ปลั๊กอินแยก `EvergardenForge` (`evergarden-forge/`, 0.5.1) นำวงจรของดรอปแบบ Apotheosis มาใช้ผ่านเมนู GUI แทนโต๊ะ ไม่แก้ JAR ของ Evergarden / Advance Magic โต๊ะ Enchant คง Vanilla ไอคอนควบคุมเมนูใช้ชุด Skill Tree / menu ของ Advance Magic ส่วน Gem และวัสดุมีแพ็ก Forge แยกสำหรับ Java และ Bedrock

## 0.5.0: ตรวจธุรกรรมและเพิ่มภาพ Gem / วัสดุ

- Gem 8 ธาตุ × 5 ขั้น, วัสดุ 5 เกรด และผงอัญมณี รวม **46 ภาพต้นฉบับ** แต่ละขั้นมีรอยแตก ประกายและจุดบอกคุณภาพ ภาพ Java/Bedrock ตรงกันทุกไบต์ ดู [ภาพรวม](../evergarden-forge/art/catalog.png)
- เมื่อมีกับ Evergarden ใช้ HTTP host และตัวรวมการส่งแพ็กเดิม ส่งเป็น addon UUID แยก ไม่แก้แพ็กเดิมหรือ URL/SHA บน GitHub หากรัน Forge เดี่ยวใช้ HTTP fallback ตาม `resource-pack.port` (25569) และ `public-host` หรือชื่อโฮสต์ที่ผู้เล่นเชื่อมต่อ
- ก่อน Geyser โหลด รีสอร์สถูกคัดลอกไป `plugins/Geyser-Spigot/packs/evergarden-forge.mcpack` และ `custom_mappings/evergarden-forge.json` ต้องรีสตาร์ตเซิร์ฟเวอร์พร้อม Geyser; Geyser แยกโฮสต์ต้องคัดลอกสองไฟล์นี้ไปยังโฮสต์นั้น
- ไฟล์สำหรับติดตั้งเองถูกแยกไว้ใน `plugins/EvergardenForge/resource-packs/` และฝังอยู่ใน JAR Gem/วัสดุเก่าเพิ่มโมเดลเมื่อเข้ากระเป๋า เปิดกล่อง หรือรับไอเท็ม โดยคงข้อมูลและชื่อเดิม
- รับรู้ Relic ทั้ง `voidscape:` ที่ใช้จริงและชื่อเดิม `evergarden:` ป้องกันเครื่องมือพิเศษเข้ารีฟอร์จ/ย่อย ส่วน `relic_eternity` เป็นการอัปเกรด จึงไม่ใช้เป็นตัวตัดสินว่าเป็น Relic
- เปลี่ยน/ถอด Gem, เจียระไน และย่อย ตรวจพื้นที่รับผลลัพธ์ก่อนกินวัตถุดิบ หากไม่พอจะเก็บของเดิมไว้ครบ
- ปุ่มบนช่องตัวอย่างรับคลิกซ้าย/ขวาปกติ ปุ่มโคลน ทิ้ง สลับ hotbar และ Shift-click ไม่ทำรายการซื้อ รวมถึงเคารพ event ที่ถูกยกเลิกและสิทธิ์ที่ถูกถอดระหว่างเปิดเมนู
- ของในช่องวางเข้ากฎการตายตาม keepInventory เพียงครั้งเดียว ปิดเมนูหลังตายไม่คืนของซ้ำ
- กันมือรอง/Hopper/Crafter ใช้ Gem และวัสดุเป็นส่วนผสม vanilla และตรวจกลุ่มช่อง/ชนิด Attribute รวมถึง lore ที่ขาดหรือค้างจาก config เดิม
- `/forge reload` คืนของในเมนูก่อนโหลดค่าและรีเฟรชอุปกรณ์ผู้เล่น `/forge pack` สำหรับแอดมินแสดงสถานะและส่งแพ็กอีกครั้ง

ผ่าน **202 ข้อ** เมื่อรัน Forge เดี่ยว และ **205 ข้อ** เมื่อร่วมกับ JAR หลักเดิม + Geyser/Floodgate ใช้ผู้เล่นจำลองจริงบน Paper ตรวจ HTTP download/SHA และการเข้าตัวรวมส่งแพ็กด้วย รายงานและ receipt อยู่ใน `output/forge-audit/` ภาพเป็นพรีวิวจากไฟล์ texture ยังไม่ได้ตรวจหน้าจอไคลเอนต์ Java/Bedrock ที่เชื่อมต่อจริง

ไฟล์พร้อมใช้: `dist/evergarden-forge.jar` และ `dist/evergarden-forge-0.5.0.jar` มีไบต์ตรงกัน SHA-256 `7308eb1f332b564a1eb223744f3f603e8ce04d3d0e4a8f42b18f13d945f00820` ใช้แทน Forge เดิมเพียงไฟล์เดียว แล้วรีสตาร์ตเซิร์ฟเวอร์พร้อม Geyser รุ่น Forge เก่าและ JAR หลักทั้งสองคงเดิม

ตัวเลขทั้งหมดใน `config.yml` เป็นค่าตั้งต้นสำหรับเพลย์เทสต์ ยังไม่ได้ปรับสมดุลกับ Seraph/Revenant, Skill Tree และ Unique Enchant

## วงจร

```
มอน Elite / หีบ Structure → อุปกรณ์มีเกรด + Gem + วัสดุ
   ├─ ไม่เข้าบิลด์ → ย่อย → วัสดุช่าง (Gem ที่ใส่อยู่คืน) / Gem → ผงอัญมณี
   ├─ ชิ้นโปรด → รีฟอร์จ เลือก 1 ใน 3 (ใช้วัสดุ + เลเวล)
   └─ ใส่ Gem ในช่อง → Gem ซ้ำเจียระไนขึ้นขั้น
```

| ขั้น | ชื่อ | พลัง |

| I | แตกร้าว | ×1.0 |
| II | หยาบ | ×1.5 |
| III | เจียระไน | ×2.1 |
| IV | ไร้ตำหนิ | ×2.8 |
| V | สมบูรณ์แบบ | ×3.6 |

- **ใส่ Gem** (`/forge gems`): วางอุปกรณ์ → คลิก Gem ในกระเป๋าเพื่อเลือก → คลิกช่อง ใช้ 1 เม็ด; คลิกช่องที่มี Gem = ถอดคืนฟรี (กระเป๋าเต็มจะไม่ถอด); เลือก Gem แล้วคลิกช่องที่มี Gem = สลับ
- **เจียระไน** (`/forge cut`): Gem ชนิด/ขั้นเดียวกัน 2 เม็ด + ผงอัญมณี (2/4/8/12) + วัสดุ (I→II ผลึกใบหยก ×1, II→III ชิ้นคริสตัลคราม ×1, III→IV เกล็ดอาคมม่วง ×2, IV→V อำพันหลอมเทพ ×2) → Gem ขั้นถัดไป 1 เม็ด
- **ผงอัญมณี**: ย่อย Gem ขั้น I–V ได้ 1/2/4/7/11
- รีฟอร์จไม่ทำให้ช่อง Gem ลดลงและ Gem ที่ใส่อยู่ไม่หาย; ย่อยอุปกรณ์คืน Gem ที่ใส่อยู่
- Gem / ผง / วัสดุ ใช้แทนไอเท็ม vanilla ไม่ได้ (คราฟต์ ทั่ง smithing เตา ยา บีคอน ค้าขายชาวบ้าน โยน วาง ป้อนสัตว์ dispenser)

ไม่เกี่ยวกับ Gem คทาของ Advance Magic (Damage/Cooldown/Max) — คนละไอเท็ม คนละช่อง

| มหากาพย์ | +500% | ×6 | เพชรครบชุด | อุปกรณ์มหากาพย์ 1 · Gem 85% (II–III) · วัสดุ 1–3 | ×8 |
| ปรัมปรา | +800% | ×9 | เพชรครบชุด | อุปกรณ์ปรัมปรา 2 · Gem 100% (III–IV) · วัสดุ 2–4 | ×12 |

ดาเมจลูกธนูของโครงกระดูก Elite คูณตามเกรดด้วย (ลูกธนูไม่ใช่ Attribute จึงคูณตอนยิง) ส่วนระเบิดของ Creeper ไม่คูณ

วัสดุของอุปกรณ์ที่ดรอปขึ้นกับมิติ: **Overworld ไม้ หิน หนัง ทองแดง โซ่ ทอง ถึงเหล็กเท่านั้น** (ทุกเกรด รวมหีบ) ส่วน Nether / End สูงสุดเพชร — ไม่มีเนเธอไรต์ทั้งของดรอปและชุดที่ Elite ใส่ (ถ้า config เก่ามี NETHERITE จะถูกอ่านเป็น DIAMOND เว้นแต่ตั้ง `gear.allow-netherite: true`) ตั้งค่าใน `gear.materials.<มิติ>.<เกรด>`

ยังไม่มีท่าพิเศษ (โล่ด้านหน้า พุ่งชาร์จ พื้นอันตราย) ต้องทดสอบกับ LevelledMobs บนโฮสต์: ถ้า LevelledMobs เขียนชื่อมอนทับ ชื่อ Elite อาจไม่ขึ้น (ออร่าและดรอปยังทำงาน) และค่าคูณของ LevelledMobs จะซ้อนกับของ Elite

| แหล่ง | โอกาส |

## กล่องของ Evergarden

ทุกกล่องที่ Evergarden เติมของเอง (Landmark, จุดสำรวจ, วาฬฟ้า, ห้องสมบัติบอส, Sanctuary) ได้ของเพิ่มตอนผู้เล่นเปิดครั้งแรก:

| ของ | โอกาส |
|---|---|
| Gem | 60% ได้ 1 · 15% ได้ 2 ขึ้นไป · ~4% ได้ 3 |
| อุปกรณ์ติด Affix | 40% ได้ 1 · 8% ได้ 2 |

ได้ทั้ง Gem และอุปกรณ์ในกล่องเดียวกันได้ เกรด: ธรรมดา 15 · ดี 35 · หายาก 32 · มหากาพย์ 14 · ปรัมปรา 4 (ขั้น Gem ตามเกรด, อุปกรณ์ใน Overworld/Evergarden ยังเป็นไม้–เหล็ก) ตั้งค่าใน `evergarden-chests`

วิธีรู้ว่าเป็นกล่องของ Evergarden (ไม่ต้องแก้ Evergarden): Evergarden ติดป้ายบน chunk ทุกครั้งที่เติมสมบัติ (`whale_treasure_v1`, `exploration_chest_*`, `<บอส>_vault_*`, `<landmark>_treasure_v1`, `elemental_staff_*`, `ods_seal` …) ส่วน Sanctuary ที่ใช้ตารางของ End City นอก End ก็นับด้วย กล่องจะได้ของเพิ่มเมื่อ: อยู่ใน chunk นั้น, มีของอยู่แล้ว (Evergarden เติมไว้), ไม่ใช่กล่องที่ผู้เล่นวาง และยังไม่เคยได้ของเพิ่ม — ครั้งเดียวต่อกล่อง

ข้อจำกัด: กล่องเก็บของของผู้เล่นที่วางไว้ใน chunk สมบัติ **ก่อน** ติดตั้งปลั๊กอินนี้ และมีของอยู่ จะได้ของเพิ่ม 1 ครั้ง (กล่องที่วางหลังติดตั้งไม่โดน) กล่อง Evergarden ที่ผู้เล่นเปิดไปแล้วก่อนติดตั้งก็ได้ของเพิ่มตอนเปิดครั้งถัดไปถ้ายังมีของเหลือ

## หีบ Structure

หีบ vanilla (`chests/*`) ตอนเปิดครั้งแรก: อุปกรณ์ในหีบ 60% กลายเป็นของมีเกรด, 15% เพิ่มอุปกรณ์มีเกรด 1 ชิ้น (16 ชนิด), 20% วัสดุช่าง, 25% Gem; Ancient City / End City / Bastion / Mansion / Stronghold / Trial reward ใช้น้ำหนักเกรดสูงกว่า หีบที่ปลั๊กอินเติมเอง (ดันเจียน/บอส Evergarden) ไม่ถูกแตะ

## Reforge (อิง Apotheosis)

วางอุปกรณ์ (ธรรมดาก็ได้) + วัสดุช่าง (กำหนดเกรดผลลัพธ์) → 3 ผลลัพธ์ไม่เรียงความแรง ต้นทุน ×1/×2/×3 ผลลัพธ์ผูก seed ผู้เล่น ปิดเปิดเมนูได้ผลเดิม เปลี่ยนเมื่อรีฟอร์จสำเร็จ รักษาเอนชานต์ Limit Break Unique Enchant ชื่อที่ตั้งเอง และ Gem

ต่างจาก Apotheosis: ไม่ใช้ Gem Dust ในต้นทุนรีฟอร์จ (ใช้ในการเจียระไนแทน) และไม่มีระดับโต๊ะ ใช้ `reforge.max-rarity`

## กันฟาร์มมอน (farm-guard)

ของ vanilla และ XP จากฟาร์มได้ตามปกติ — ที่ลดคือโอกาสของ Forge (Gem จากมอนทั่วไป, การเกิด Elite, รางวัล Elite) **แบบเงียบ ไม่มีข้อความ** ตามจำนวนมอนที่เพิ่งตายแถวนั้น:

| ตีติดกันในพื้นที่เดียว (3×3 chunk) | โอกาส Forge |
|---|---|
| 1–5 ตัว | 100% |
| 10 ตัว | ~60% |
| 15 ตัว | ~37% |
| 30 ตัว | ~11% |
| ห้องฆ่าของฟาร์ม (ต่อเนื่อง) | ~0% |

ความร้อนลดครึ่งทุก 5 นาที เดินต่อไป 2–3 chunk หรือพักราว 30–45 นาที โอกาสกลับมาเต็ม คนเดินสำรวจ (ฆ่าแล้วเดินต่อ) ได้เต็ม 100% ตลอด มอนที่บาดเจ็บจากสิ่งแวดล้อมก่อนตาย (ตก ลาวา Magma ติดบล็อก เบียดกัน จมน้ำ กระบองเพชร หิมะผง) ไม่ได้ของ Forge เลย — ไฟจากแดดไม่นับ ไม่มีเพดานต่อชั่วโมง (`ordinary-gems-per-hour: -1`)

ประมาณการ Gem ต่อชั่วโมงของคนเดินสำรวจตอนกลางคืน (ฆ่า ~40 ตัว): Overworld ~1–1.5 เม็ดจากมอน (มอนทั่วไป ~0.4 + Elite ~2 ตัว × 35–60%), Nether ~2 เม็ด (Elite มหากาพย์/ปรัมปรา 85–100%) — ยังไม่รวมหีบ กล่อง Evergarden และการขุด
