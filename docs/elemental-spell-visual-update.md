# Advance Magic: อัปเดตภาพเวทและคัมภีร์

รุ่น 1.14.0 เพิ่มไอคอนคัมภีร์เฉพาะครบ 58 เวท มีสีและตราธาตุ พร้อมกรอบระดับ Basic, Rare, Epic และ Legendary แพ็ก Java ใช้ item model ของแต่ละคัมภีร์ ส่วน Bedrock ใช้ texture และ Geyser mapping ที่แยกชื่อไอเท็มตามเวท

เอฟเฟกต์ร่ายใช้อนุภาคตามธาตุเพิ่มขึ้น: ไฟมีเปลว, น้ำมีละออง, น้ำแข็งมีเกล็ดหิมะ, ลมมีหมอก, ดินมีเศษมอส, แสงมีประกาย, มืดมีพอร์ทัล และสายฟ้ามีประกายไฟฟ้า อนุภาคเหล่านี้เป็นของ Minecraft จึงแสดงได้ผ่าน Geyser โดยไม่ต้องติดตั้งเอฟเฟกต์ไคลเอนต์เพิ่ม

## ติดตั้ง

1. ปิดเซิร์ฟเวอร์ แล้วแทน `plugins/advance-magic.jar` ด้วย `advance-magic.jar` ในไฟล์ ZIP นี้
2. เปิดเซิร์ฟเวอร์ใหม่: Java จะดาวน์โหลด resource pack จากปลั๊กอิน ส่วน Geyser จะรับ Bedrock pack และ mapping ที่ปลั๊กอินฝังไว้
3. ให้ Geyser รีสตาร์ตพร้อมเซิร์ฟเวอร์ แล้วให้ผู้เล่นเชื่อมต่อใหม่ หาก Java ไม่ได้รับแพ็ก ให้ตรวจ `/magic pack` และลอง `/magic pack resend`

ไฟล์ `advance-magic-java.zip`, `advance-magic-bedrock.mcpack` และ `geyser-mappings.json` แนบมาแยกสำหรับตรวจสอบหรือใช้ติดตั้งเอง ไฟล์ PNG ใน `elemental-scroll-icons/` เป็นภาพไอคอนต้นฉบับ 58 ชิ้น

การปรับนี้แก้รูปลักษณ์คัมภีร์กับอนุภาคตามธาตุ คทาเดิมยังใช้โมเดลที่มากับแพ็ก Advance Magic อยู่ เวทที่ใช้ภาพจำลองจากบล็อก/เอนทิตีจะยังแสดงตามรูปทรง vanilla ที่เกมมี
