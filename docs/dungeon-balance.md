# วิหาร Tier I–V — e2.151

แก้ความยากของวิหารความมืด ดวงดาว และกาลเวลาใน Evergarden โดยเน้น Tier IV–V และไล่ค่า Tier I–III ให้ต่อเนื่องกัน

| ค่าเล่นคนเดียว | Tier IV เดิม → ใหม่ | Tier V เดิม → ใหม่ |
|---|---:|---:|
| บอส HP | 920 → 620 | 1024 → 740 |
| เกราะพื้นฐาน | 24 → 9 | 26 → 10 |
| Armor toughness | 16 → 5 | 18 → 6 |
| ลดดาเมจเพิ่มเติม | 38% → 13% | 45% → 15% |
| เพดานดาเมจตีปกติ ก่อนเกราะผู้เล่น | 56.7 → 21 | 64.8 → 24 |
| อัศวิน HP / ดาเมจ | 195 / 19 → 125 / 12 | 240 / 22 → 150 / 14 |
| ภูตเวท HP / ดาเมจ | 170 / 17 → 105 / 10 | 210 / 20 → 125 / 12 |
| นักล่ามิติ HP / ดาเมจ | 220 / 22 → 145 / 14 | 270 / 25 → 175 / 16 |
| Vex HP / ดาเมจ | 15 / 20 → 12 / 9 | 18 / 23 → 14 / 10 |

เพดานดาเมจเดิมในตารางเป็นขอบบนของตัวกรองเดิมก่อนบังคับลดค่า (`maxMelee * 1.35`) ไม่ใช่ค่าโจมตีพื้นฐาน และยังมีการเรียกดาเมจเสริมอีก event 10/13 หน่วย ส่วนค่าใหม่เป็นเพดานจริงที่ไม่รวมสถานะ Wither ฯลฯ

- HP บอสทั้งห้าระดับ: **360 / 440 / 520 / 620 / 740** เพิ่มต่อเพื่อนหนึ่งคน **50 / 60 / 70 / 80 / 90** สูงสุดเพื่อนสองคน (Tier IV สูงสุด 780, Tier V สูงสุด 920) `combat.boss-health` ยังเป็นเพดานที่แอดมินลดได้
- ดาเมจไม่เพิ่มตามจำนวนผู้เล่นหรือจำนวนผู้เล่นที่เคยเข้าลาน ลูกมอนเพิ่มเลือดตามเพื่อนสูงสุดสองคนเช่นกัน
- เอาดาเมจเสริมจากการตีบอสออก สกิลวงเวท เลเซอร์ และพื้นอันตรายไม่เรียกเอฟเฟกต์ตีปกติหรือสะสม True Death ซ้ำ โหมด Hard ไม่คูณสกิลเกินงบดาเมจที่กำหนด
- True Death ยังสะสมจากการโจมตีปกติที่ไม่ถูกบล็อก/ยกเลิกใน Tier III ขึ้นไป
- ตัวคูณสกิลทั้งห้าระดับเป็น **0.67 / 0.75 / 0.83 / 0.90 / 1.00**
- Vex สูงสุดสามตัวใน Tier III–V และจำนวนที่อัญเชิญไม่ล้นเพดาน
- Cataclysm Tier IV/V พัก 37.5/34 วินาที ก่อนคลั่ง และ 25.5/22 วินาทีหลังคลั่ง พื้นอันตราย Tier V จากทุก 16 เป็น 24 วินาที คำเตือนก่อนระเบิดยังอยู่
- ป้องกันการเพิ่มค่าโจมตีหรือเกราะพื้นฐานจากปลั๊กอินภายนอก แม้ค่า HP ไม่ได้เปลี่ยน โดยไม่ฮีลมอนระหว่างล้างค่า

## การตรวจสอบและติดตั้ง

`DungeonBalanceChecks.java` ผ่าน **479 เช็ก** บน Paper จริง: สามชนิดวิหาร ห้าระดับ ทีม 1/3/20 คน อุปกรณ์จริง การโดนตี/ตีผู้เล่นจริง การล้างค่าที่ถูกเพิ่มจากภายนอก การยกเลิกดาเมจ และสกิลที่ไม่สร้างดาเมจหรือคำสาปซ้ำ เทียบความถึกจากการโดน raw 20 กับเลือดบอสโลกเดี่ยว 7000 เป็นขอบเขตตรวจสอบ ไม่ใช่การวัดเวลาฆ่าหรือความยากทั้งหมดของไฟต์ ยังต้องลองกับผู้เล่นจริงเพื่อจูนความรู้สึกการเล่น

```powershell
python tools/build_dungeon_balance_release.py
python tools/run_dungeon_balance_checks.py --source-server output/vault-balance-20261026/paper-active-v2
python tools/build_dungeon_balance_release.py --promote
```

บิลด์ทับฐานล่าสุดโดยเปลี่ยนเฉพาะ DungeonManager, DungeonBalance และเวอร์ชันปลั๊กอิน เก็บ JAR เดิมที่ `output/dungeon-balance-20261026/before/evergarden.jar` รายงานผลอยู่ใต้ `output/dungeon-balance-20261026/paper/`

ใช้ `dist/evergarden.jar` แทน JAR บนเซิร์ฟเวอร์แล้วรีสตาร์ต ไม่ต้องอัปเดต resource pack บิลด์ไม่ได้ติดตั้งให้เซิร์ฟเวอร์จริงอัตโนมัติ
