# Advance Magic 1.18.0 — Native Spell VFX

เปลี่ยนภาพเวทธาตุทั้ง 58 เวทให้ใช้สิ่งที่มีอยู่ใน Minecraft เป็นหลัก
แทนแผ่นภาพขนาดใหญ่ รูปทรงจะเคลื่อน หมุน แผ่ กระจาย และสลายตัวตามจังหวะเวท

| ธาตุ | วิธีแสดงผล |
| --- | --- |
| ไฟ | Fireball ใช้ SmallFireball แบบ Blaze; Meteor Rain ใช้ LargeFireball แบบ Ghast พร้อมเปลวไฟ ควัน และระเบิดของเกม |
| น้ำ | ละอองน้ำ ฟอง และสันคลื่นที่เคลื่อนผ่านพื้นที่จริง |
| น้ำแข็ง | เกล็ดหิมะ เศษน้ำแข็ง และผลึกจากบล็อกของเกม |
| ลม | คมลม ฝุ่นขาว และเกลียวพายุที่หมุนขึ้นเป็นชั้น |
| ดิน | เศษบล็อก หินสามมิติ และวงกระแทกพื้น |
| แสง | ประกาย End Rod เสาแสง และแสงที่แผ่ออกจากจุดปะทะ |
| มืด | Portal หมึก และกลุ่มอนุภาคที่ยุบเข้าศูนย์กลาง |
| สายฟ้า | ประกายไฟและเส้นฟ้าที่แตกแขนงตามแนวโจมตี |

Phoenix และ Leviathan ใช้รูปทรงที่ประกอบจากพาร์ติเคิลด้วย จึงไม่ต้องโหลดรูปเวท
เพื่อเห็นเอฟเฟกต์ชุดใหม่ Resource pack เดิมยังใช้สำหรับคทา ไอเทม และระบบภาพเก่า

## ความเห็นต่อระบบเดิม

ระบบคัมภีร์ ช่องเวท คูลดาวน์กลาง และปฏิกิริยาธาตุมีโครงสร้างที่ต่อยอดได้
จุดที่ควรปรับก่อนคือภาพและการตอบสนอง: แผ่นภาพถูกใช้แม้กับลูกไฟ ฝน
รอยปะทะ และสถานะเล็ก ๆ ทำให้เวทจำนวนมากให้ความรู้สึกคล้ายกัน

รุ่นนี้ให้ความสำคัญกับแนวเคลื่อนที่ ปริมาตร และจังหวะปะทะของแต่ละชนิด
ตัวเลขบาลานซ์ยังต้องประเมินด้วยการเล่นจริง โดยเฉพาะ PvP และเวทขั้นสูง
การตรวจบนเซิร์ฟเวอร์บอกความถูกต้องของกลไกได้ แต่ไม่ได้ตัดสินความสวยจากภาพจริงบน client

## ตั้งค่า

```yaml
elemental-visuals:
  enabled: true
  style: native
  quality: balanced
  sounds: true
  max-scenes: 96
  max-native-particles-per-world-tick: 1200
  max-native-particles-per-viewer-tick: 220
  max-native-displays-per-world: 80
  max-native-projectiles-per-world: 48
```

`style: native` เป็นค่าเริ่มต้นเมื่อ config เดิมยังไม่มีค่านี้
`quality: low` ลดรายละเอียดภาพ `style: authored` ใช้เปรียบเทียบกับภาพวาดชุดเดิม

เอฟเฟกต์หลักใช้พาร์ติเคิลมาตรฐานทั้ง Java และ Bedrock ผ่าน Geyser
Java มี BlockDisplay ของบล็อกเกมเสริมปริมาตรด้วย ส่วน Bedrock ใช้รูปทรงพาร์ติเคิล
เพราะ Geyser ไม่แสดง BlockDisplay การประเมินความลื่นและความหนาแน่นของภาพบนทั้งสอง client
ยังต้องทำในเกมจริง

## ลูกไฟและการติดตั้ง

ลูกไฟที่เพิ่มเป็นตัวแสดงภาพ วิถีชนและผลโจมตียังคำนวณโดยระบบเวทธาตุ
มีการปิดดาเมจ การเผา การทำลายบล็อก และการตีลูกไฟกลับของตัวแสดงภาพ
พร้อมล้างเมื่อลูกเวทจบ ยกเลิกร่าย เจ้าของออกจากเกม ตาย เปลี่ยนโลก หรือปลั๊กอินหยุด
เอฟเฟกต์ภาพไม่ใช้ช่อง EffectEngine เพิ่ม

หยุดเซิร์ฟเวอร์แล้วแทน `plugins/advance-magic.jar` ด้วยไฟล์รุ่นนี้ จากนั้นเริ่มเซิร์ฟเวอร์
ใช้ Evergarden และ resource pack ชุดเดิมได้ รุ่นนี้เปลี่ยนโค้ดเอฟเฟกต์โดยไม่ต้องสร้างแพ็กภาพใหม่

## ผลตรวจ

ทดสอบ JAR ที่ส่งมอบบน Paper 26.3 ที่แคชไว้ในโปรเจกต์ ผ่าน **1,842 ข้อ**
รวมเวทธาตุทั้ง 58 เวท เส้นทางภาพเดิมและภาพใหม่ การเคลื่อนและใช้ entity ลูกไฟซ้ำ
การกันดาเมจ/ไฟ/ระเบิดของตัวแสดงภาพ การล้างเมื่อเปลี่ยนโลกหรือออกเกม
และการนับ packet พาร์ติเคิลที่ส่งถึงผู้เล่นจำลองจริงตามงบที่ตั้งไว้
ผลนี้เป็นการตรวจบนเซิร์ฟเวอร์ ยังไม่ได้ตรวจภาพที่แสดงจริงบน Java/Bedrock client
