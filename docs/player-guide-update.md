# คู่มือผู้เล่นและอินโฟกราฟิกแพตช์ Evergarden

รุ่น Advance Magic `1.3.5-player-guide` / Evergarden `3.0.0-e2.18-player-guide`

## คู่มือในเกม

เปิด `/evergarden guide` เพื่ออ่านฉบับปัจจุบันได้ทั้ง Java และ Bedrock
คู่มือเวทมนตร์มี 18 บท ครอบคลุมคทา 17 ธาตุ, มานา, การคราฟต์, ความทนทาน,
แกนอัปเกรดทั้งสามแบบ, แท่นฟื้นฟูและลานซาก, Wand of Restoration, ไม้เท้าบิน
และแหล่งแกน Mythic ใหม่ คู่มือยุทธภัณฑ์เพิ่มบทแหล่งสมบัติ Whale / Garden /
Observatory และแก้คำอธิบายหน้าเลือกคู่มือเป็นจำนวนไอเท็มปัจจุบัน

ตัวเลขในคู่มือเป็นค่าเริ่มต้นของระบบเซิร์ฟเวอร์ หมวด Mythic Core ใน Vault รวม
0.5% เลือกหนึ่งใน Levitation / Sun / Time เท่า ๆ กัน

## ภาพสำหรับผู้เล่น

- [คู่มือภาพฉบับปัจจุบัน](../advance-magic/dist/advance-magic-guide-th.png)
- [Evergarden — New Patch Update](patch-notes/evergarden-new-patch-update.png)

อินโฟกราฟิกแพตช์เน้นภาพไอเท็มฟื้นฟูและคทา Mythic ใหม่สองอัน ข้อความมีเฉพาะ
แหล่งหาไอเท็ม, วิธีใช้สั้น ๆ, ความสามารถหลัก และลานซากที่ใช้ซ่อมไม่ได้แต่แตะ
หินกลางลานเพื่อดูพิกัดแท่นใกล้เคียงได้

สร้างด้วย built-in `image_gen.imagegen` ใช้ภาพไอเท็มและโมเดลจากโปรเจกต์เป็น
ภาพอ้างอิง บันทึก [prompt ทั้งสองและภาพอ้างอิง](patch-notes/guide-image-prompts.json)
รูปแบบไอเท็มในภาพเป็นภาพประกอบจากอ้างอิง ไม่ใช่ภาพหน้าจอการเล่นในเกม

## การติดตั้ง

ใช้ JAR ทั้งสองใน root `dist` แล้วรีสตาร์ตเซิร์ฟเวอร์ เปิดเมนูคู่มือหรือรับ
หนังสือเล่มใหม่เพื่ออ่านเนื้อหาปัจจุบัน ภาพคู่มือใหม่ฝังใน Advance Magic JAR
ด้วย แพ็กไอเท็มยังเป็น Advance Magic 2.3.0 / Evergarden 3.10.0

Build ด้วย Maven `-DskipTests` รอบนี้ไม่รัน tests หรือเปิดเซิร์ฟเวอร์จริง
