# กฎใส่ Unique Enchant ร่วมกัน

คัมภีร์ที่อยู่ในกลุ่มเดียวกันเลือกได้หนึ่งชนิดต่ออุปกรณ์หนึ่งชิ้น:

| กลุ่ม | พลังที่เลือกได้หนึ่งอย่าง |
| --- | --- |
| ธนูโจมตี | Colossus Slayer, Ricochet, Absolute Zero, Singularity, Meteor Arrow |
| ประชิดโจมตี | Guillotine, Echo Strike, Blade Vortex, Thunderlord, Titan Breach |
| ฟื้นเลือด | Soul Harvest, Vampiric |
| ขุดหลัก | Seismic Slam, Vein Smelter, Advance Tool |

Unique enchant groups remain mutually exclusive. Blade Vortex conflicts with Soul Harvest and Vampiric; Advance Tool conflicts with melee powers. Mining powers cannot be added to Rift Pickaxe or Smelter Pickaxe because their special effects occupy that slot.

Soulbound ใช้ร่วมกับ Scroll of Eternity ไม่ได้ ไม่ว่าจะลงคัมภีร์ใดก่อน Kinetic Grapple, Telepathy, Phoenix Rebirth, Shadow Step และ Titan Stance เป็นพลังเสริมที่ยังใส่ร่วมกับพลังหลักในช่องอุปกรณ์ที่รองรับได้ Soulbound ยังใส่กับพลังอื่นได้ตามปกติ ยกเว้น Eternity

กฎเดียวกันใช้กับการลากคัมภีร์ การใช้คัมภีร์ในมือ โต๊ะคราฟต์ เมนูอัปเกรด และฟอร์ม Bedrock คัมภีร์ที่ใช้ไม่ได้จะไม่ถูกกิน

ไอเท็มเก่าที่มีพลังขัดกันจะเก็บข้อมูลทุกคัมภีร์ไว้ แต่พลังส่วนเกินจะไม่ทำงานจนกว่าจะตัดสินใจ ผู้เล่นถือไอเท็มแล้วพิมพ์ `/upgrade` เพื่อเลือกพลังที่ต้องการเก็บ พลังที่ถอดออกคืนเป็นคัมภีร์ตามจำนวนจริง ต้องมีช่องว่างในกระเป๋าพอรับคัมภีร์ และหากมีหลายกลุ่มขัดกันให้เลือกแก้ทีละกลุ่ม เมนู Bedrock จะเปิดตัวเลือกเดียวกันเมื่อเลือกอุปกรณ์นั้น
