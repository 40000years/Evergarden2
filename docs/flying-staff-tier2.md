# ไม้เท้าบินระดับ 2 · อัครปักษา

Advance Magic `1.32.0-tandem-flight` คู่กับ Evergarden `3.0.0-e2.145-tandem-flight`

- ผู้ขับ 1 คน และผู้ซ้อน 1 คน ผู้ขับขึ้นก่อน แล้วผู้ซ้อนคลิกไม้เท้าหรือที่นั่งหลัง ไม่ต้องถือไม้เท้าเอง
- ความเร็ว 50% ของรุ่นปกติ ทั้งขึ้น ลง เดินหน้า ถอยหลัง และ Turbo ใช้การควบคุมเดิม
- ใช้มานา 150% ของรุ่นปกติ หักจากผู้ขับเท่านั้น แม้บินคนเดียว ค่าเริ่มต้น 3 มานา/วินาที และ Turbo 4.5 มานา/วินาที
- ความทนทานและการซ่อมเหมือนรุ่นปกติ เรียกสำเร็จเสีย 1 ครั้ง ขึ้นซ้อนและลงไม่เสียเพิ่ม
- `/evergarden test` → **คทาธาตุ & ไม้เท้าบินระดับ 1–2** → ไม้เท้าบินระดับ 2 ที่ช่อง 20 (นับจาก 0) รุ่นปกติยังอยู่ช่อง 26
- ผู้ซ้อนลงด้วยย่อง รับ Slow Falling ขณะลง ผู้ขับลงแบบเดิม หากมานาหมดเหนือ Void ส่งทั้งคู่กลับจุดปลอดภัย

โมเดลใหม่มี 90 ชิ้น โครงงาช้าง ขอบทอง คริสตัลฟ้า ปีกหัวไม้เท้า อานหนังสองตำแหน่ง ที่จับและที่วางเท้า ระยะที่นั่ง 1.35 บล็อก โมเดล Java และ Bedrock มีรูปทรงและพาเลตเดียวกัน ใช้ท่าเรียก รอ บิน และเก็บของเดิม

- [ภาพตัวอย่างโมเดล](../advance-magic/art/flying-staff/flying_staff_tier2-preview.png)
- [ไฟล์แก้ต่อใน Blockbench](../advance-magic/art/flying-staff/flying_staff_tier2.bbmodel)
- สร้าง asset ซ้ำด้วย `python tools/flying_staff_tier2_assets.py`
- แพ็กแจกจริงอยู่ใน `advance-magic/dist/` และฝังใน JAR แล้ว Bedrock pack version `2.34.0` ใช้ UUID เดิม

ผลตรวจและสำเนา release อยู่ใน `output/tandem-flight-20261026/` ทดสอบบน Paper จริงด้วยผู้เล่นจำลอง ครอบคลุมตำแหน่งผู้โดยสาร ความเร็ว มานา การชนหัวที่นั่งหลัง การเลี้ยวและถอยชนกำแพง การออกจากเกม การสูญเสียไอเทม การส่งกลับจาก Void และเส้นทางเมนูทดสอบ ตรวจระบบบินรุ่น 1 และระบบ Gem เดิมร่วมด้วย ภาพตัวอย่างเรนเดอร์จากโมเดล ยังไม่ได้ตรวจภาพผ่านไคลเอนต์ Minecraft จริง

ผลชุดสุดท้าย: รุ่น 2 ผ่าน 665 รายการ ระบบบินเดิมผ่าน 269 รายการ (40,764 กรณี input) ระบบ Gem ผ่าน 2,747 รายการ และแพ็กผ่าน 4,005 รายการ ไม่มี runtime exception ในชุดทดสอบ
