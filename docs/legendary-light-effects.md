# Heaven's Descent — Legendary Light ฝนแสงและแรงดูด

รุ่น `1.26.4-radiant-rain` ปรับคัมภีร์เดิม `heavens_descent` ธาตุแสง ระดับ Legendary เป็นฝนแสงตกเป็นระลอก พร้อมเสียงร่ายและแรงกระแทก แรงดูดศัตรูเข้ากลาง และดาเมจต่อเนื่องที่แรงขึ้น วงเวท ละอองสี และวงเล็กช่วยยิงยังใช้ทรัพยากรร่วมกันสำหรับ Java และ Bedrock

## ทดลองในเกม

ใช้ปลั๊กอิน `dist/advance-magic-1.26.4-radiant-rain.jar` แทน JAR เดิม หรือใช้ `dist/advance-magic.jar` แล้ว restart เซิร์ฟเวอร์ รุ่นนี้ใช้แพ็ก 2.28.0 เดิม ไม่ต้องสร้างหรือดาวน์โหลดทรัพยากรภาพใหม่ ฝั่ง Geyser ที่อยู่ในเซิร์ฟเวอร์เดียวกันจะได้รับ Bedrock pack ตอนปลั๊กอินเริ่มโหลด

ผู้เล่นที่มีสิทธิ์ admin ใช้:

```text
/spell give staff light mythic
/spell give scroll heavens_descent
```

ถือคทาแสง เปิด `/spell` แล้วใส่คัมภีร์ Heaven's Descent เลือกช่องเวทนั้นและคลิกขวาร่าย คทาต้องเป็นระดับ Mythic เพื่อรับคัมภีร์ Legendary และใช้มานา 85 ตามเดิม

## รูปแบบฉาก

- ร่าย 30 ticks (ประมาณ 1.5 วินาที) ตามเวลาของเวทเดิม
- วงพื้นชั้นใน 14 บล็อก วงนอก 26 บล็อก
- วงฟ้าเป็นแนวนอน ขนาด 21 บล็อก พร้อม halo 25 บล็อก สูงจากวงพื้น 32 บล็อก
- วงเวททุกวงวางบนระนาบ XZ รวมช่วงเริ่มร่ายและวงเล็กที่โคจร 4 ระดับ
- เปลี่ยนภาพหมอกคอลัมน์เป็นละอองสีชิ้นเล็กที่ลอยหมุนในช่วงล่างของช่องว่าง โดยยังมองทะลุฉากได้
- ฝนแสงเป็นลำแสงสั้นหลายสายสลับกันตกจากฟ้าลงพื้น แต่ละสายยาว 22% ของระยะบน–ล่าง ตกถึงพื้นภายใน 12 ticks และเริ่มหยดใหม่ทุก 16 ticks โดยเปลี่ยนจุดตก ไม่เชื่อมค้างเป็นเสาตลอดความสูง
- วงเล็ก 4 วงโคจรด้านนอกที่ระดับ 7, 9.5, 12 และ 14.5 บล็อก ผลัดกันยิงลำแสงจากตำแหน่งวงไปด้านนอก
- ลำแสงจากวงช่วยยิงยังเป็นเอฟเฟกต์ ส่วนพื้นที่ฝนแสงด้านในเป็นพื้นที่ดาเมจและแรงดูดจริง
- ภาพคงอยู่หลัง impact อีก 600 ticks (30 วินาที) รวมช่วงร่ายประมาณ 31.5 วินาที แล้วหดสลาย
- วงพื้น วงฟ้า และ halo หมุนสวนกันประมาณ 20–32 องศาต่อวินาที โดยเฟสต่อเนื่องผ่านจังหวะ impact
- Balanced สูงสุด 12 display layers ต่อฉาก พร้อมฝน 3 สาย; Low สูงสุด 7 layers พร้อมฝน 1 สายและวงช่วยยิง 2 วง ละอองและแสงกระทบพื้นส่งท้ายภายใต้งบ packet เดิม
- มานา 85 และ cooldown 90 วินาทีตามเดิม

## ดาเมจ แรงดูด และเสียง

- ตัวคูณดาเมจรวมเพิ่มจาก 4 เป็น 16 เท่าของ offensive spell power: รวมแรงขึ้น 4 เท่าจากรุ่นก่อน เมื่ออยู่ในวงครบทุกจังหวะ
- เปิดฉากใช้ 25% ของงบรวม (= 4 เท่าของ power) จากนั้นฝนแสงแบ่งอีก 75% เป็น 15 จังหวะ เริ่มที่ 1 วินาทีและเกิดทุก 2 วินาทีจนครบช่วง 30 วินาที จังหวะละ 0.8 เท่าของ power
- ดาเมจจริงยังผ่านระบบธาตุ คทา เกราะ และ protection เดิม ไม่ใช่การหัก HP ตรง
- รัศมีดาเมจและแรงดูด 7 บล็อกตรงกับวงใน ศัตรูที่รับ damage event สำเร็จจะถูกดึงแนวนอนเข้ากลาง โดยอ่อนแรงใกล้จุดศูนย์กลาง ไม่มี teleport หรือการล็อก frozen
- ตรวจความเป็นศัตรู กฎ PvP ทีม protection และแนวการมองเห็นก่อนดึงทุกครั้ง ใช้ `context.velocity` จึงรักษาการตั้งค่าแรงผลักผู้เล่นและการจำกัดความถี่เดิม บอสไม่ถูกเคลื่อนย้าย และเพดานดาเมจบอสต่อการร่ายยังทำงาน
- ฮีลพันธมิตรและบัฟลดดาเมจหนึ่งครั้งตอนเปิดฉากตามเดิม
- เสียงเป็น native sound: Beacon/Amethyst/Bell ช่วงร่าย ตามด้วย Thunder/Portal ตอนเปิดฉาก และเสียงฝนกระทบสลับเสียงบรรยากาศทุกวินาที ใช้ `elemental-visuals.sounds` และหมวด PLAYERS
- เอฟเฟกต์จบเมื่อหมดเวลา ร่ายใหม่ ผู้ร่ายตาย ออกจากเกม เปลี่ยนโลก หรือศูนย์กลางไม่อยู่ใน chunk ที่โหลด

ปรับแรงดูดได้ โดย config เดิมที่ไม่มีค่านี้จะใช้ 0.5:

```yaml
elemental-combat:
  legendary-light:
    pull-strength: 0.5 # 0 ปิดแรงดูด; สูงสุด 0.9
```

ค่านี้เปิดภาพวงเฉพาะ Heaven's Descent แม้เซิร์ฟเวอร์ใช้ `elemental-visuals.style: native` ส่วน duration ใช้ร่วมกับระยะเวลาของสนามโจมตี:

```yaml
elemental-visuals:
  legendary-light:
    enabled: true
    scale: 1.0
    sky-height: 32.0
    duration-seconds: 30
```

ตั้งแต่รุ่น 1.26.2 ใช้ `duration-seconds` และละเลย `afterglow-ticks` เดิม จึงไม่ติดค่า 170 ticks จาก config ของรุ่นก่อน ระยะเวลาใหม่จำกัด 5–60 วินาที และระดับความสูงจำกัด 16–64 บล็อกพร้อมขอบความสูงของโลก

## งานภาพและแพ็ก

ภาพวงเวทเดิมสร้างด้วย built-in ImageGen ขนาด 1254 × 1254 แล้วจัดลง texture canvas 2048 × 2048 พร้อมขอบ alpha โปร่งใส ภาพต้นฉบับอยู่ใน `advance-magic/art/effects/legendary-light/source/`; คำสั่งสร้างภาพอยู่ใน `generation-prompts.json` และรายละเอียดไฟล์อยู่ใน `manifest.json` ภาพวงเดิมคงเดิมทุกไบต์ ส่วนภาพหมอกเก่ายังอยู่ในแพ็กเพื่อรักษาทรัพยากรเดิม แต่ฉาก Legendary รุ่นนี้ไม่เรียกใช้

ภาพลำแสงและละอองสีสร้างด้วย `tools/generate_legendary_light_beams.py` โดยบันทึกรายละเอียดใน `technical-vfx-manifest.json` รุ่นฝนแสงใช้ภาพ beacon เดิมในลำแสงสั้นที่เคลื่อนลง Java ใช้ ItemDisplay แบบ full brightness: วงเป็นโมเดลสองด้าน และลำแสงเป็นโมเดลสี่หน้า วงหมุนใช้ interpolation 3 ticks และระยะมองเห็น 96 บล็อก ละอองใช้ native DUST ขนาด 1.15–1.75 จำนวน 24 จุดต่อเฟรม ภายใต้งบรวม 64 particles ต่อผู้ชมต่อ real server tick

Bedrock ใช้ custom particle ผ่าน Geyser: วงเป็นระนาบ XZ พร้อม `line_rotation_rate` เพื่อหมุนต่อเนื่อง ลำแสงจัดแนวด้วย `direction_y` และละอองเป็น sprite หันเข้ากล้อง ลอยหมุนและจางเอง โดยกำหนด origin ที่พื้น `line_width` เป็นเส้นผ่านศูนย์กลาง และ `line_height` เป็นความสูงขึ้นจากพื้น ค่าขนาดครึ่งด้านของ sprite เท่ากับ 0.22–0.34 บล็อก Bedrock pack version เป็น 2.28.0

ดูงานภาพและจังหวะจำลองได้ที่ `previews/legendary-light/index.html` ซึ่งเป็นพรีวิว Canvas จาก PNG จริง ภาพจำลองนี้ไม่ใช่ภาพจับจากตัวเกม

อัปเดตแพ็กเฉพาะส่วนโดยรักษาไอคอนคัมภีร์ 58 ใบและไฟล์อื่น:

```text
python tools/build_legendary_light_resources.py
python tools/preview_legendary_light.py
```

## การสร้างไฟล์รุ่น 1.26.4

```text
python tools/build_legendary_light_rain_release.py
```

คอมไพล์ Java 25 ผ่านทั้ง 3 source ที่แก้ไข (18 classes) โดยใช้ JAR รุ่น 1.26.3 เป็นฐาน แทนเฉพาะกลุ่มคลาสเวทแสงและ config/plugin metadata เพื่อแยกการส่งมอบครั้งนี้จากงานอื่นใน workspace ทรัพยากรภาพและแพ็กใน JAR คงเดิม รายงานอยู่ที่ `output/light-rain-v4-build-20261024/release-build.json`

รุ่น 1.26.4 ยังไม่ได้รันทดสอบ gameplay บนเซิร์ฟเวอร์หรือดูภาพและเสียงจากไคลเอนต์จริง ผลทดสอบด้านล่างเป็นของรุ่น 1.26.3 ก่อนเพิ่มฝนแสง ดาเมจและ CC

## ผลตรวจรุ่น 1.26.3 ก่อนหน้า

คอมไพล์ source ใหม่ทั้ง 73 ไฟล์ด้วย JDK 25 ผ่านเครื่องมือ build ของโปรเจกต์ ไม่ใช้คลาสจาก incremental build

Real Paper smoke probe ผ่าน 56 ข้อ: ตรวจวงแนวนอน ระยะห่าง 32 บล็อก การหมุน เสาแสงทอดลง วงเล็กยิงซ้ำจากตำแหน่งคงที่ขณะยิง งบ display/particles การคงอยู่ 600 ticks การร่ายจริง damage/heal ครั้งเดียว และ cleanup รายงานอยู่ที่ `output/light-beacon-v3-smoke-20261023/heavens-descent-visual-validation.json`

Geyser จริงผ่าน 23 ข้อด้วย CaptureSession และ production bridge: ตรวจวง `_flat`, native spin, เสาแสง, วงเล็กทั้ง 4 วงปล่อยลำแสงซ้ำ, ละออง native และ auto-install mcpack 2.28.0 ตรงกับ JAR ฉากพร้อมกัน 8 ฉากใน 96 real ticks ส่งสูงสุด 12 packets ต่อผู้ชมต่อ tick รายงานอยู่ที่ `output/light-beacon-v3-bedrock-20261023/heavens-descent-bedrock-validation.json`

ตรวจไฟล์แพ็ก CRC, entry ซ้ำ, UV, model routes, ภาพทั้งสองฝั่งตรงกัน, hash และการรักษาทรัพยากรเดิมผ่าน รายงานอยู่ที่ `output/legendary-light-effects/resource-validation.json`

JAR รุ่น 1.26.3 ตรงกับ hash ในรายงานทั้งสองฝั่ง รายละเอียดการส่งมอบรุ่นก่อนอยู่ที่ `output/legendary-light-effects/release-validation.json` รุ่น 1.26.4 เปลี่ยนโค้ดต่อสู้ตามคำขอใหม่ จึงไม่ใช้ผลทดสอบเก่ารับรองการทำงานของ CC และดาเมจใหม่ ไฟล์ที่ส่งมอบยังอยู่ใน workspace ไม่ได้ติดตั้งลงเซิร์ฟเวอร์ที่ใช้งานจริง

ยังต้องตรวจภาพและ FPS จากไคลเอนต์ Java/Bedrock จริง การทดสอบเซิร์ฟเวอร์และการตรวจแพ็กไม่ยืนยันผลการเรนเดอร์บน GPU ของผู้เล่น
