## e2.127: เกาะหัวไม่ลอยตาม · ฟักไข่จากเมนู · โมเดลใหม่

**เกาะหัว (Java):** เดิมเซิร์ฟเวอร์ย้ายชิ้นโมเดลไปที่หัวทุก tick ภาพจึงตามหลังหัวเท่ากับ ping บวกการ interpolate เลยดูลอยตาม ตอนนี้เซิร์ฟเวอร์บอกไคลเอนต์ของผู้ชมแต่ละคนว่าชิ้นโมเดลขี่อยู่บนผู้เล่น ไคลเอนต์จึงพาสัตว์ไปกับหัวทุกเฟรม ไม่มีดีเลย์ ฝั่งเซิร์ฟเวอร์ไม่มี passenger จริง `/spawn` วาร์ป และข้ามโลกจึงใช้ได้ตามเดิม สัตว์หันตามหัวแบบนุ่ม ๆ และเงยหน้า/ก้มตามที่เจ้าของมอง Bedrock ยังใช้วิธีเดิม

**ผสมพันธุ์และฟักไข่:** ระบบทำงานครบ ตรวจบน Paper ทั้งผ่านเมนูจริง (เลือกคู่ → เริ่ม → เก็บไข่ → ฟัก)
- หน้า **รังผสมพันธุ์** แสดงไข่ที่พกอยู่และเปอร์เซ็นต์ กด **ฟักไข่!** ได้เลย (Bedrock มีปุ่มในฟอร์ม) เพราะผู้เล่นมือถืออาจแตะกลางอากาศด้วยไอเท็มธรรมดาแล้วไม่ส่งถึงเซิร์ฟเวอร์
- ฟักจากมือซ้าย (off-hand) ได้
- ถ้าไฟล์คอกอ่านไม่ได้ ระบบไม่ยอมให้ฟัก (เดิมฟักได้แต่ลูกจะหายตอนรีสตาร์ต)
- แอดมินทดสอบเร็ว: `/evergarden pets rush <ผู้เล่น>` ทำให้รังและไข่ที่พกอยู่พร้อมทันที

## 1. การเทม

1. หาสัตว์ป่าใน Evergarden ([วิธีพบสัตว์ป่า](wild-pets.md)) ถืออาหารที่มันชอบ แล้วคลิกขวาที่ตัว ใช้ได้ทั้ง Java และ Bedrock
2. ป้อนแต่ละครั้งความไว้ใจจะเพิ่มขึ้น แสดงเป็นหลอดใน action bar
   - ร่างเด็ก: +18–30 ต่อครั้ง ประมาณ 4–5 ครั้ง
   - ร่างกลาง: +9–16 ต่อครั้ง และมีโอกาส 25% ที่มันไม่สนใจ
   - ร่างโตเต็มวัย: +4–8 ต่อครั้ง มีโอกาส 25% ที่ไม่สนใจ และถ้าไม่สนใจ มีโอกาส 8% ที่จะหนีไป
3. คนแรกที่ป้อนได้สิทธิ์ 60 วินาที คนอื่นแย่งป้อนไม่ได้ ระหว่างเทมสัตว์จะไม่หมดอายุ และตัวที่บินอยู่จะลงมาหาคนที่ถืออาหาร

## 2. คอกและตัวติดตาม (`/pet`)

- **เมนู:** `/pet` เปิดคอก 6 ช่อง (ปรับได้) Java เป็น chest menu ส่วน Bedrock เป็นฟอร์ม
- **ในเมนูทำได้:** เรียกหรือเก็บตัวติดตาม, เลือกโหมด, ดูสกิล, ตั้งชื่อ, ใส่รัง, ปล่อยคืนธรรมชาติ (ต้องยืนยัน), เปิดหรือปิดการซ่อนสัตว์ของคนอื่น และดูอาหารที่ชอบ
- **คำสั่งลัด:** `/pet summon [ลำดับ|ชื่อ]` · `/pet dismiss` · `/pet list` · `/pet name <ชื่อ>` · `/pet mode <follow|stay|perch|assist>` · `/pet skills` · `/pet hide`
- **คลิกขวาสัตว์ของตัวเอง:** ถืออาหารที่ชอบเพื่อป้อน (เติบโต +5 · ผูกพัน +2 · พักท้อง 60 วินาที), ถือ Name Tag เพื่อตั้งชื่อ หรือมือเปล่าเพื่อเปิดการ์ดข้อมูล
- **คลิกสัตว์ของคนอื่น:** เห็นชื่อเจ้าของ

### ตั้งชื่อ

ตั้งชื่อได้ 3 ทาง ไม่มีทางไหนใช้แชท จึงใช้ได้แม้แชทของผู้เล่นถูกปิด เช่น log ขึ้นว่า `Chat disabled due to missing profile public key`

| ทาง | ใช้อย่างไร |
| --- | --- |
| ปุ่ม **ตั้งชื่อ** ในเมนู | Java เปิดหน้าเขียนป้าย พิมพ์ชื่อบรรทัดบน (ยาวได้ 2 บรรทัด) แล้วกด Done · Bedrock พิมพ์ในฟอร์ม |
| Name Tag | ตั้งชื่อ Name Tag ที่ทั่งก่อน แล้วคลิกขวาที่สัตว์ Name Tag ถูกใช้ 1 อัน · Name Tag ที่ยังไม่ตั้งชื่อจะเปิดหน้าเขียนป้ายแทน |
| `/pet name <ชื่อ>` | ตั้งชื่อตัวที่ติดตามอยู่ · `/pet name` เฉยๆ เปิดหน้าเขียนป้าย |

- **ป้าย:** เป็นป้ายปลอมที่เห็นเฉพาะผู้เล่นคนนั้น วางในช่องว่างที่ไม่มี block entity ใกล้ตัว แล้วคืนบล็อกจริงทันทีหลังพิมพ์
- **ชื่อ:** ยาวไม่เกิน 16 ตัวอักษร โค้ดสี `§` และ `&` จะถูกตัดออก

| **อยู่กับที่** (stay) | ยืนรอตรงที่อยู่และหันมองเจ้าของเมื่ออยู่ใกล้ 10 บล็อก ถ้าเจ้าของห่างเกินนั้นจะนั่งรอ ถ้าห่างเกิน 64 บล็อกจะวิ่งตามมาและกลับเป็นโหมดติดตาม |
| **เกาะบนหัว** (perch) | ตัวเล็กลงแล้วนั่งบนหัวเจ้าของ หันตามที่เจ้าของมอง |
| **ช่วยสู้** (assist) | ไล่กัดตัวที่เจ้าของตีหรือยิง และมอนที่กำลังหมายหัวเจ้าของ ในรัศมี 16 บล็อก |

**เกาะบนหัว**

- **ขนาด:** ร่างเด็ก 55% · ร่างกลาง 38% · ร่างโตเต็มวัย 28%
- **ไม่บังการคลิก:** ตัวรับคลิกถูกซ่อนจากทุกคน ชิ้นส่วนโมเดลขี่หัวเจ้าของบนไคลเอนต์ (ไม่ใช่ passenger จริง) การขุดหรือคลิกเหนือหัวจึงไม่ติดสัตว์
- **ไม่ใช้ passenger:** Paper 26.3 ไม่ยอมให้ผู้เล่นที่มี passenger วาร์ปข้ามโลก ระบบจึงย้ายตามหัวแทนการขี่ เพื่อให้ `/spawn` หรือวาร์ปไปดันเจี้ยนยังใช้ได้
- **Bedrock:** ตัว Bedrock ถูกย่อด้วย attribute `scale` ยังไม่ได้ลองกับเครื่อง Bedrock จริง

**ช่วยสู้**

- **ไม่ตี:** ผู้เล่น สัตว์เลี้ยง บอส NPC และสัตว์ที่เจ้าของเลี้ยงไว้เอง
- **ไล่ไม่ถึง:** ถ้าติดกำแพงหรือหน้าผาเกิน 3 วินาที จะเลิกไล่แล้วกลับมาหาเจ้าของ
- **เครดิตการฆ่า:** นับเป็นของเจ้าของ มอนจึงดรอปของและ XP ตามปกติ

## 2.3 สลบและพักฟื้น

เฉพาะโหมดช่วยสู้ที่สัตว์เจ็บได้ โหมดอื่นยังเป็นอมตะเหมือนเดิม

- **โดนสวน:** ทุกครั้งที่กัด ศัตรูมีโอกาส 35% สวนกลับ ดาเมจเท่าแรงตีของมอนตัวนั้น
- **ระเบิด:** ระเบิดในระยะ 6 บล็อกก็ทำดาเมจ
- **ดูเลือด:** เลือดขึ้นใน action bar ทุกครั้งที่โดน และฟื้นเอง 5% ต่อวินาทีเมื่อพ้นการต่อสู้ 5 วินาที
- **เลือดหมด:** สัตว์สลบและกลับเข้าคอก พักฟื้น **1 วันในเกม** (24,000 tick หรือ 20 นาทีที่ 20 TPS)
  - ระหว่างนี้เรียกตัวนั้นไม่ได้ แต่เรียกตัวอื่นได้
  - ครบเวลาแล้วกลับมาหาเจ้าของเองพร้อมเลือดเต็ม
- **เวลาพักฟื้น:** นับจากนาฬิกาเกมของโลก Evergarden `/time set` จึงข้ามไม่ได้ และรีสตาร์ตก็ไม่รีเซ็ต
- **เมนู:** การ์ดสัตว์และ `/pet list` บอกเวลาที่เหลือ

ปรับได้ที่ `pets.companions.stay-leash`, `assist-radius`, `counter-chance` และ `faint-ticks`

### พฤติกรรมเดินตาม

- **ระยะ:** เดินตามอยู่ด้านหลังเยื้องข้าง ห่าง 3–6 บล็อก ถ้าไกลกว่า 8 บล็อกจะวิ่ง ก้าวขึ้นลงได้ 1 บล็อก และไม่เดินตกขอบเกาะ
- **เจ้าของนั่งนิ่ง:** สัตว์จะนั่งพักเมื่อเจ้าของยืนนิ่งเกิน 12 วินาที
- **ตัวที่บินได้:** บินตามเมื่อเจ้าของลอยอยู่ เช่น ขี่คทาบิน ร่อนลงข้างตัว หรือตกจากเกาะ และลงจอดเมื่อเจ้าของกลับมายืนบนพื้น
- **ตามไม่ทัน:** ถ้าห่างเกิน 24 บล็อก สัตว์จะวาร์ปมาข้างเจ้าของ ถ้าหาที่ยืนปลอดภัยไม่ได้นาน 10 วินาที จะพักไว้ก่อน แล้วกลับมาเองเมื่อมีที่ยืน
- **ย้ายโลก:** ตามข้ามโลกได้ เว้นโลกที่อยู่ใน `pets.companions.disabled-worlds`

### หลบชั่วคราวแล้วกลับมาเอง

สัตว์จะหายไปชั่วคราวเมื่อเกิดเหตุเหล่านี้ และกลับมาเองเมื่อเหตุหมดไป

| เหตุ | กลับมาเมื่อ |
| --- | --- |
| ใกล้การต่อสู้กับบอส (บอสโลก, Arkhaia, วิหารที่กำลังสู้) ในรัศมี 40 บล็อก | ไม่มีบอสในระยะนาน 10 วินาที |
| เจ้าของ AFK 5 นาที | เจ้าของขยับหรือพิมพ์แชท |

| ออกจากเกม | เข้าเกมใหม่ |

## 3. การเติบโต

แต้มเติบโตได้จาก 3 ทาง

| ที่มา | แต้ม |
| --- | --- |
| อยู่ด้วยกันขณะเจ้าของไม่ AFK | +1 ต่อนาที |
| ป้อนอาหารที่ชอบ | +5 |
| พิชิตบอสในระยะ 64 บล็อก | +20 |

- **เกณฑ์เปลี่ยนร่าง:** ครบ 120 แต้มเปลี่ยนเป็นร่างกลาง (เล่นจริงประมาณ 2 ชั่วโมง) ครบ 360 แต้มเปลี่ยนเป็นร่างโตเต็มวัย (ประมาณ 6 ชั่วโมง)
- **ตอนเปลี่ยนร่าง:** ขึ้นข้อความกลางจอ และโมเดลเปลี่ยนในที่เดิมทั้ง Java และ Bedrock
- **ความผูกพัน:** +1 ทุก 10 นาทีที่อยู่ด้วยกัน และ +2 ต่อการป้อนอาหาร
- **กันปั๊ม:** ช่วง AFK ไม่นับทั้งแต้มเติบโตและความผูกพัน

## 4. การขยายพันธุ์

การผสมพันธุ์ทำในเมนูทั้งหมด ไม่มีการปล่อยสัตว์หลายตัวไว้ในโลก

- **เงื่อนไข:** ตัวโตเต็มวัย 2 ตัว ชนิดเดียวกัน และความผูกพันตั้งแต่ 50 ขึ้นไปทั้งคู่
- **ค่าใช้จ่าย:** อาหารที่ชอบ ×8
- **ระยะเวลา:** รอในรัง 30 นาที แล้วกดเก็บไข่
- **ข้อจำกัด:** พ่อและแม่พักผสมพันธุ์ 24 ชั่วโมง และผู้เล่นแต่ละคนได้ไข่ไม่เกิน 2 ฟองต่อวัน
- **การฟัก:** พกไข่ไว้ในกระเป๋าขณะออนไลน์ 20 นาที แล้วคลิกขวาเพื่อฟัก ไข่แลกเปลี่ยนกันได้ และใครฟักก็ได้ลูกเข้าคอกของคนนั้น
- **ไข่อยู่ในบัญชีของเซิร์ฟเวอร์:** ข้อมูลไข่และลูกที่จะเกิดเก็บใน `pets/eggs.yml` ระบบบันทึกว่าไข่ถูกฟักแล้วก่อนเพิ่มสัตว์เข้าคอก ไข่ที่ถูก dupe จึงฟักซ้ำไม่ได้ และไข่ใช้คราฟเป็นหนังสือ แผนที่ หรือพลุไม่ได้

ลูกที่ฟักออกมาได้รับคุณสมบัติดังนี้

| คุณสมบัติ | กฎการสืบทอด |
| --- | --- |
| พลังชีวิต · ว่องไว · มนตรา (0–31) | สุ่มจากพ่อหรือแม่ แล้ว ±เล็กน้อย มีโอกาส 5% ได้ +5 |
| ขนาด 85–115% | เฉลี่ยจากพ่อแม่ ±4% (ตัวที่เทมจากป่ามีขนาด 100%) |
| ออร่า | ถ้าพ่อหรือแม่มี โอกาส 25% ถ้าไม่มี โอกาส 2% |
| รุ่น | รุ่นที่สูงกว่าของพ่อแม่ +1 |

ค่าสถานะมีผลต่อเลือด แรงกัด และความถี่ในการกัด ดู [2.2 สกิลและพลังต่อสู้](#22-สกิลและพลังต่อสู้)
