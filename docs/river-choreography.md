# Six Rivers — e2.81

ไฟล์พร้อมติดตั้ง: `dist/evergarden.jar` รุ่น `3.0.0-e2.81-river-choreography`
ใช้ ModelEngine R4.1.1 และแพ็ก Bedrock 3.29.0

| ตัว | ท่าและพฤติกรรม |
| --- | --- |
| Acheron | กางดาบคู่ บิดลำตัวฟันขวาง ท่าพิเศษหมุนสองรอบในครึ่งวินาที พร้อมวงฟันเลือด |
| Phlegethon | ยกกำปั้นทั้งสอง รวบพลังที่เตาอก แล้วทุ่มแขนปล่อย Ghostflame |
| Cocytus | ยกธนูตั้งตรง ง้างมือขวาและสะบัดปล่อยสาย ยิงลูกธนูจริงพร้อมรอยน้ำแข็งและ slow เมื่อโดน ยืนยิงเมื่ออยู่ในระยะ 10 บล็อก |
| Banshee Wail | หุบมือเข้าใกล้หน้า แอ่นตัวรวบลมหายใจ แล้วกางแขน อ้าปากและสะบัดผ้าคลุมกรีดร้อง |
| Malefeasance | ยกคัมภีร์ลอยด้วยมือขวา ชูมือซ้ายแล้วสะบัดสั่งเงา มีการเคลื่อนไหวของหน้าหนังสือและ familiar |
| Styx | หมุนชุดแขนและขวานร่วมกัน ยกคมขวานเหนือหัวแล้วจามลงด้านหน้า มือทั้งสองรักษาตำแหน่งจับด้าม มีเสียงกระแทกหนักและช่วงเสียหลักหลังท่าพิเศษ |

การโจมตีปกติมีระยะ/ความเร็วต่างกัน: Acheron เร็วที่สุด ส่วน Styx ง้างนานที่สุด
จุดเกิดผลอยู่ที่คีย์สัมผัสของแต่ละคลิป (ความเร็วคลิปเปลี่ยนตามเวลาจริง)
Cocytus ยิงได้ไกล 18 บล็อก, Banshee ใช้เสียงระยะ 7 บล็อก และ Malefeasance ยิงเวทระยะ 10 บล็อก
ท่าพิเศษยังใช้วงเตือนก่อนเกิดผล ลูกธนูปกติหลบได้และชนกำแพงได้
ลูกธนูเป็นของ encounter หยิบไม่ได้ และลบเมื่อชน หมดอายุ เจ้าของตาย หรือจบการทดสอบ/การต่อสู้

แทนที่ JAR แล้วรีสตาร์ตเซิร์ฟเวอร์ จากนั้นเข้าเกมใหม่เพื่อรับแพ็ก
ตัวติดตั้งจะอัปเกรด blueprint ที่จัดการโดย Evergarden พร้อมสำรองไฟล์เดิม
หากเคยแก้ blueprint เอง ให้ดูคำเตือนใน console เพราะระบบจะรักษาไฟล์ที่ไม่ใช่ของตัวติดตั้งไว้
ใช้ `/evergarden test` → Six Rivers → แถว combat เพื่อทดสอบทีละตัว

ภาพและ GIF ที่ `previews/river-choreography/` เรนเดอร์จาก bbmodel ที่ส่งจริง
เป็นภาพตรวจโครงกระดูก ไม่ใช่ภาพจับจาก Minecraft

## การตรวจสอบ

- `python tests/model-engine/check_river_choreography.py`: สุ่มตรวจคมอาวุธไม่ทะลุอก/หัว การจับด้าม การหมุน 720 องศา ท่าง้างธนู และแนวจามขวาน
- `python tests/model-engine/check_river_assets.py`: ถอดรหัสแพ็กจริงและเปรียบเทียบ pose/geometry ระหว่าง Java และ Bedrock
- `python tests/model-engine/check_bedrock_rig.py`: ตรวจสเกเลตันหลักและนาฬิกาคลิป
- isolated Paper + official ModelEngine R4.1.1 + Geyser/Floodgate/LevelledMobs: ผ่าน 284 ข้อ รวม GUI การต่อสู้ การยิงลูกธนูจริงจากระยะ 8 บล็อก การติด slow และการทำความสะอาด entity (ผลที่ `output/river-choreography-combat-me-20261015/model-engine-result.txt`)

ตรวจ geometry/pose parity ในแพ็กผ่าน 16,416 ข้อ และ choreography/อาวุธผ่าน 41,008 ข้อ
ยังไม่ได้ตรวจภาพขณะเชื่อมต่อด้วยไคลเอนต์ Java/Bedrock จริง

ต้นฉบับท่าต่อสู้สร้างซ้ำด้วย `python tools/update_river_choreography.py`
แล้วสร้างแพ็กด้วย `python evergarden/tools/build_packs.py`
สร้างภาพตรวจด้วย `python tools/preview_river_choreography.py`
