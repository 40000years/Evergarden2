## ติดตั้ง

1. ปิดเซิร์ฟเวอร์ แล้วแทน `plugins/advance-magic.jar` ด้วยไฟล์รุ่นนี้ จากนั้นเปิดใหม่
2. Java รับ resource pack ที่ฝังใน JAR; ตรวจ `/magic pack` และใช้ `/magic pack resend` หากยังใช้แพ็กเก่า ผู้ใช้ CDN ภายนอกให้อัปโหลด Java ZIP ใหม่และตั้ง SHA-1 ตรงกับ `pack-hashes.json`
3. Geyser บน Spigot ได้รับ Bedrock pack/mapping ผ่านระบบติดตั้งเดิมก่อนเริ่ม Geyser ให้รีสตาร์ต Geyser พร้อมเซิร์ฟเวอร์ และให้ผู้เล่นเชื่อมต่อใหม่ เวอร์ชัน Bedrock pack เป็น **2.17.0**
4. ใช้ Evergarden JAR ที่มีเมนูเสกคัมภีร์เดิมได้

## ปรับภาพ

เพิ่มค่าใน `plugins/advance-magic/config.yml` ได้ดังนี้ หากไม่มีจะใช้ค่าเริ่มต้นนี้:

```yaml
elemental-visuals:
  enabled: true
  quality: balanced
  sounds: true
  max-scenes: 96
  max-planes-per-world: 128
  bedrock-packets-per-viewer-tick: 12
```

`balanced` ใช้ภาพที่วาดพร้อมชั้นประกอบ ส่วน `low` ใช้เส้น/จุดโครงร่าง เมื่อใช้งบภาพครบ renderer จะลดรายละเอียดภาพ โดยระบบต่อสู้ใช้ช่อง EffectEngine ของเดิม ภาพแต่ละ scene ถูกล้างเมื่อสิ้นอายุ เจ้าของตาย/ออก/เปลี่ยนโลก หรือปลั๊กอินหยุด

จำกัด Basic/Rare ที่ 6 display, Epic 8 และ Ultimate 12 ต่อ scene พร้อมเพดานรวม 128 ต่อโลกตามค่าเริ่มต้น ภาพหลักมีสิทธิ์แทนที่เครื่องหมายสถานะหรือแสง hit ขนาดเล็กเมื่อโควตาเต็ม รายละเอียดรองใช้ได้ไม่เกิน 3 packet ต่อผู้ชมต่อ tick และกันงบให้ภาพหลักก่อน ภาพทั้งหมดรวมกันยังอยู่ในเพดาน packet ที่ตั้งไว้

Java ใช้ ItemDisplay และ Bedrock ใช้ custom world particle ตามเทคนิคชุด Solar/Chronos/Judgment เดิม รูปมังกร ปีก และศิลาเป็นภาพโปร่งที่ประกอบหลายระนาบ การมองแต่ละมุมจึงอาจต่างกันระหว่างสอง client

## การตรวจรุ่นนี้

ทดสอบ JAR รุ่นนี้โดยตรงผ่านแล้ว:

- Paper regression **1,451 ข้อ** ครบ 58 เวท รวมภาพหลัก Ultimate ทั้ง 10, ภาพ Epic เมื่อมีสถานะหลายเป้าหมาย, เพดาน display, การใช้ display ซ้ำ และการล้างภาพเมื่อยกเลิกร่าย
- การโหลดร่วมกับ Evergarden + Geyser/Floodgate **280 ข้อ** พร้อมตรวจการติดตั้งแพ็ก
- ไฟล์เอฟเฟค **1,261 ข้อ** ตรวจ item → model → texture, ภาพ Java/Bedrock ตรงกัน และ pack ที่ฝังใน JAR
- โมเดลและไฟล์คทาเดิม **4,277 ข้อ**

การตรวจอัตโนมัติใช้เซิร์ฟเวอร์ localhost ชั่วคราว ส่วนการเปรียบเทียบภาพที่ render จริงบน Java/Bedrock client และการวัดหลายผู้เล่นยังต้องประเมินด้วยการเล่นจริง
