# Retired legendary armor

The Aegis, Kavacha and Aegishjalmur custom armor system was removed in Advance Magic 1.11.2. Commands, wearable models, capes, effects and Java/Bedrock resources are no longer shipped. Existing items are converted to native Netherite armor when accessed; enchantments and other item data are preserved.

Use the rebuilt `dist/advance-magic.jar`. Bedrock pack version: 2.14.2. Historical validation snapshots under `output/` are not deployable releases.
