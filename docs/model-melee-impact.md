# เสียงฟันโดนบอสโมเดล · e2.103

บอสที่ใช้ตัวรับดาเมจซ่อนอยู่และระบบเลือดของ encounter จะไม่ได้เสียงเจ็บตามปกติของมอนสเตอร์ เมื่ออาวุธประชิดลดเลือดบอสได้จริง รุ่นนี้เพิ่มเสียงกระแทกให้ผู้โจมตีโดยตรง จึงได้ยินชัดแม้จุดกำเนิดของโมเดลยักษ์อยู่ห่างจากตำแหน่งที่ฟัน

เสียงประกอบด้วยจังหวะโจมตีประชิดเดิม เสียงกระแทกทุ้มสั้นของ mace และเสียงโลหะเบา ๆ ใช้เสียง Minecraft ที่มีอยู่แล้ว ไม่ต้องเปลี่ยน resource pack หรือติดตั้งเสียงเพิ่ม เสียงส่งเฉพาะผู้ฟัน และจำกัดหนึ่งชุดต่อผู้เล่นต่อ server tick เพื่อไม่ให้การกวาดโดนหลายเป้าหมายทำให้เสียงซ้อนดังเกินไป

ครอบคลุม Arkhaia บอสแม่น้ำทั้งหก ร่างแยกและเงาที่ใช้ระบบยืนยันการลดเลือดร่วมกัน รวมถึงมือและแกนของ Ancient Judge เสียงกระแทกใหม่เล่นเฉพาะการโจมตีประชิดที่ encounter ยอมรับ หลังตรวจระยะ มุม กำแพง คูลดาวน์ โล่ และการกันดาเมจแล้ว ธนูใช้เสียงยืนยันเดิม เวทมนตร์ไม่เพิ่มเสียงกระแทกประชิด และตัวอย่างสัตว์เลี้ยงไม่รับดาเมจ

ติดตั้ง `dist/evergarden.jar` เวอร์ชัน `3.0.0-e2.103-melee-impact` แทนไฟล์เดิมแล้วรีสตาร์ตเซิร์ฟเวอร์ ไม่ต้องเปลี่ยน config

โค้ดเสียงอยู่ใน `ModelMeleeImpact.java` จุดเรียกใช้คือ `ArkhaiaHitFeedback.confirm()` และสาขาที่ `JudgmentFight.Hit.damage() > 0` ของ `WorldBossManager` การยกเลิก native damage event โดย encounter เป็นส่วนหนึ่งของระบบเลือดเสมือน จึงยืนยันจากผลลดเลือดจริงแทนการฟังทุก damage event ทั่วเซิร์ฟเวอร์

การตรวจบน Paper ใช้ `tests/arkhaia/MeleeImpactProbe.java` ตรวจ sound packet ที่ส่งถึงผู้เล่นเทียบกับเลือด encounter รวมทั้งการฟันพลาด การกันประชิด และการแยกธนู/เวทมนตร์ การตรวจแพ็กเก็ตยืนยันว่าเซิร์ฟเวอร์ส่งเสียงถูกจังหวะ แต่ระดับความหนักแน่นของเสียงยังขึ้นกับระดับเสียงและอุปกรณ์ของผู้เล่น

ผลตรวจรุ่นสุดท้าย: **PASS 193 รายการบน Paper** รวมเสียงของมือและแกน Judge การฟันถึงตาย และการกันเสียงซ้อนเมื่อโดนหลายเป้าหมายใน tick เดียว พร้อมกฎ encounter เดิม **67,143 รายการ** รายงาน: [arkhaia-result.txt](../output/melee-impact-paper-v5-20261021/arkhaia-result.txt)
