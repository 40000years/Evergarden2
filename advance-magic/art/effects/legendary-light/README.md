# Legendary light VFX textures

Runtime cleanup in `1.27.2-reused-runes` removes the unused legacy mist texture and
its definitions from downloadable packs. Its original files remain here. Active
sigil, halo, light-rain and mote pixels are unchanged.

Textures for the existing `HEAVENS_DESCENT` Legendary light scroll, reused by `1.26.4-radiant-rain`:

- `elemental_legendary_light_sigil.png`: intricate geometric celestial wheel.
- `elemental_legendary_light_halo.png`: annular runic halo for counter-rotation.
- `elemental_legendary_light_mist.png`: retained legacy mist artwork; the v3 scene does not emit it.
- `elemental_legendary_light_beacon.png`: separated coloured lanes and a white core, now used as short falling rain streaks.
- `elemental_legendary_light_shot.png`: thin ray fired by the orbiting helper seals.
- `elemental_legendary_light_mote.png`: small transparent petal sprite used by the native Bedrock emitter.

The original sigil, halo and legacy mist were created with built-in ImageGen and remain byte-identical. `source/` retains the native generated RGBA images, including iterations. `generation-prompts.json` records the complete prompt set, reference frame and selected versions. The selected 1254px sources are uniformly resampled inside an 1800px area on a 2048px transparent texture canvas. `manifest.json` records those texture hashes and source files. The new technical beam and mote sprites are generated by `tools/generate_legendary_light_beams.py`; `technical-vfx-manifest.json` records their dimensions and hashes.

Both clients consume identical PNG bytes for the shared artwork. Java renders unshaded double-sided ring models and four-sided ray models through ItemDisplay at full brightness. All runic circles remain horizontal XZ planes; the upper pair is 32 blocks above the ground pair. Java rotation finishes interpolation in three ticks and uses a 96-block viewing range. Bedrock registers `particles_blend` planes, horizontal variants and direction-aligned beam emitters, with UV dimensions derived from each source texture. The Geyser `line_*` bridge supplies pose and native `line_rotation_rate` in degrees per second. Bedrock pack version is 2.28.0.

The v3 middle field uses small drifting coloured motes instead of painted mist columns. Java uses 24 native DUST particles per frame, size 1.15–1.75, sharing a 64-particle per-viewer real-tick budget across scenes. Bedrock uses one native emitter packet per frame, spawning 24 short-lived camera-facing sprites with half-size 0.22–0.34 blocks. Its origin is the field floor: `line_width` is the full diameter, `line_height` is the upward extent, and `line_offset_*` is the exact sub-block offset from the packet origin. This keeps all particles above the floor.

The v4 scene replaces the persistent sky-to-floor shaft with three staggered falling streaks (one on Low). Each streak spans at most 22% of the height, falls in 12 ticks and repeats with a new landing point every 16 ticks. Four horizontal helper seals still alternate anchored cosmetic rays. The separate gameplay field now deals opening damage plus 15 rain pulses at the default duration, with a total multiplier of 16, and pulls permitted enemies within seven blocks toward the centre. Native bells, thunder and impact sounds accompany the field. The stage and combat field share the default 30-second duration. Balanced keeps at most 12 display layers; Low keeps at most seven. Existing packs remain version 2.28.0.

The previous v3 JAR passed 56 real Paper checks and 23 Geyser packet checks. The v4 JAR has Java 25 compilation and archive packaging only; no new gameplay or live-client visual/audio tests were run. Its build record is `output/light-rain-v4-build-20261024/release-build.json`. See `docs/legendary-light-effects.md` for gameplay details and historical reports.
