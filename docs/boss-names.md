# ชื่อบอสสีไล่โทน (Evergarden e2.195-boss-names)

[ภาพตัวอย่าง Java / Bedrock](../previews/boss-names/boss-bars.png)

ชื่อบอสบนหลอดเลือด ชื่อเหนือหัวบอสวิหาร และข้อความ "ถูกสังหารโดย ..." ใช้หน้าตาเดียวกันจาก
`evergarden/src/main/java/com/example/voidscape/boss/BossNames.java`:

- ไอคอนสองข้าง ชื่ออังกฤษตัวหนาไล่สี 2 โทน แล้วตามด้วยชื่อไทยสีเดียว เช่น `✹ VHAROK ✹ · มังกรเพลิงโลกันตร์`
- ชื่อที่มีแต่ภาษาไทย (ผู้พิพากษาไร้ร่าง) ไล่สีทีละตัวอักษร โดยสระและวรรณยุกต์ติดไปกับพยัญชนะ ไม่ทำตัวหนา
- Bedrock: Geyser ปัดสี hex เป็นสีที่ใกล้ที่สุดของ Bedrock ชื่อจึงเป็นแถบสี 2–3 สีแทนการไล่สีละเอียด
- บอสที่ไม่มีในตาราง (เช่นบอสใหม่ในอนาคต) ได้สีแดงเลือด `☠ ชื่อ ☠` อัตโนมัติ

| บอส | ไอคอน | สี |
| --- | --- | --- |
| VHAROK (มังกรไฟ) | ✹ | แดงลาวา → ส้มทอง |
| VAELTHYR (มังกรสายฟ้า) | ⚡ | ม่วง → ทอง |
| GLACERYN (มังกรน้ำแข็ง) | ❄ | ขาวน้ำแข็ง → ฟ้า |
| Cinder Colossus / Soul-Eater Hound / Crystal Moth Queen / Unlit Sun | ♨ ☠ ❖ ☀ | ตามธาตุของบอส |
| Shadow Overlord / Astral Archon / Chronos Vanguard (วิหาร) | ☠ ✦ ⚙ | ม่วง / ฟ้า-ม่วง / ทอง |
| SERAPHON, ผู้พิพากษาไร้ร่าง, Arkhaia, Malefeasance | ✦ ⚖ ⚔ ✧ | ขาวทอง / ม่วง / ม่วง / ชมพู-ม่วง |
| Acheron, Phlegethon, Cocytus, Banshee Wail, Styx | ☠ ♨ ❄ ☽ ☠ | เขียว / ไฟ / น้ำแข็ง / ม่วงอ่อน / คราม |

เปลี่ยนสีหรือไอคอน: แก้บรรทัด `new Look("ชื่อ", ..., "ไอคอน", สีเริ่ม, สีจบ, สีชื่อไทย)` ในตาราง `LOOKS` แล้ว build ใหม่
(`python tools/build_plugin_jars.py`) ข้อมูลของบอสไม่เปลี่ยน ชื่อที่ระบบบันทึกไว้สำหรับข้อความตายก็ยังเป็นข้อความเดิม
