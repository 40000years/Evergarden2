# Evergarden — ดินแดนขนาดใหญ่ 4 ไบโอม

รุ่น `3.0.0-e2.53-continental-biomes` เปลี่ยนพื้นที่ใหม่ของ Evergarden ให้เป็นผืนเกาะลอยฟ้าขนาดใหญ่
มีเทือกเขา ป่าลึก และซากนครให้เดินสำรวจ โดยยังใช้มิติ `evergarden` และไอเท็มเดิม

## ลักษณะพื้นที่

| ไบโอม | ภูมิประเทศและสิ่งที่พบ |
| --- | --- |
| `gardens` | สวน Evergarden ต้นเชอร์รี่พุ่มกว้าง โคมไฟ ดอกไม้ และสวนผลึก เกาะเกิดกับวิหารเริ่มต้นคงรูปแบบเดิม |
| `glacier` | เทือกเขาหิมะและธารน้ำแข็งมหึมา ชั้น Packed Ice / Blue Ice หนา ผลึกน้ำแข็งสูง และซุ้มโค้งธรรมชาติกว้างราว 80–92 บล็อก |
| `ancient-forest` | ป่าไม้หลายชนิด พื้นมอสและรากไม้ ต้นโบราณสูงประมาณ 50–65 บล็อก กิ่งแตกหลายชั้น รากค้ำ เห็ดยักษ์ และหินที่ปกคลุมด้วยพืช |
| `lunar-city` | เขตนครจันทราที่สาบสูญ ถนนสีขาวและหินเข้ม ซากโถง หอคอย ลานวงแหวน เสาจันทร์เสี้ยว บ่อน้ำสะท้อนจันทร์ สวนผลึก และต้นไม้สีซีด |

สเกลเริ่มต้น **3,072 บล็อกต่อช่องไบโอม** ขอบเขตจริงบิดโค้งตาม seed และบางพื้นที่ของชนิดเดียวกันอาจต่อกัน
จึงไม่ใช่เกาะตกแต่งขนาดเล็กหรือแผนที่สี่เหลี่ยม 3,072×3,072 ทุกเขต ความสูงกับพื้นดินค่อย ๆ ผสมกันตามแนวรอยต่อ
รวมถึงจุดที่หลายไบโอมมาชนกัน ร่องแยกแคบยาวเปิดให้เห็นช่องว่างใต้ผืนเกาะ โดยพื้นที่ส่วนใหญ่ของแต่ละเขตยังเป็นพื้นต่อเนื่อง

ใช้บล็อก Minecraft ปกติทั้งหมด Java และ Bedrock จึงเห็นภูมิประเทศเดียวกัน ไม่ต้องเพิ่ม resource pack สำหรับไบโอม
ระบบนี้ไม่ได้เพิ่มบอสหรือสัตว์เลี้ยงใหม่

## โครงสร้างเดิม

วาฬลอยฟ้า หอดูดาว สวนแขวน วิหารใหญ่ และสถาปัตยกรรม Arkhaia / Valkyrie / Seraphon
ยังสุ่มเกิดได้ในทุกไบโอม ตำแหน่ง seed ความหายาก พิกัดทางเข้า และสมบัติยังใช้ layout เดิม

พื้นที่ใหม่มีสองลักษณะตามตำแหน่งของ structure:

- **ลอยแยก:** ลดระดับพื้นด้านล่างโดยกำหนดระยะห่างขั้นต่ำจากใต้เกาะจริง 22–32 บล็อก
  วาฬลอยแยกเสมอ ส่วนอาคารอื่นสุ่มลักษณะนี้ตาม seed
- **เชื่อมกับภูมิประเทศ:** ต่อพื้นขึ้นใต้ฐานเดิมและไล่ระดับพื้นที่รอบ ๆ ให้เป็นเนินเชื่อมกับผืนหลัก
  ไม่เติมดินเข้าไปในตัวอาคาร ทางเดิน หรือช่องว่างภายใน

ขอบรอบ structure ไล่ระดับระยะ 112–160 บล็อก มีมุมโค้ง แทนการเว้นพื้นเป็นช่องว่างสี่เหลี่ยม
การปรับนี้เปลี่ยนภูมิประเทศรอบอาคารและใต้ฐาน จึงไม่จำเป็นต้องย้ายตัวอาคารหรือแก้ตำแหน่งของระบบสมบัติ

## อัปเกรดโลกที่มีอยู่

แทนที่ `dist/evergarden.jar` ในโฟลเดอร์ plugins แล้วรีสตาร์ต
ระบบจะบันทึก region ที่เคยสร้างแล้วลง `plugins/Evergarden/world-layout.yml` เพียงครั้งเดียว
region เหล่านั้นยังใช้ตัวเจนเดิมสำหรับ chunk ที่เหลือ และมีระยะเปลี่ยนผ่าน 192 บล็อกด้านนอก
บล็อกที่มีอยู่กับสิ่งที่ผู้เล่นแก้ไขไม่ถูกสร้างทับ

ดังนั้น **ไบโอมใหม่จะพบในพื้นที่นอก region เดิม** ไม่จำเป็นต้องลบโลก หากสำรวจไปไกลแล้วให้ใช้คำสั่งค้นหาไบโอมใหม่
พื้นที่รอบจุดเกิดรัศมี 384 บล็อกยังเป็นรูปแบบเดิมและค่อย ๆ เปลี่ยนเข้าสู่ผืนเกาะใหม่ภายนอก

ตั้งขนาดก่อนสร้าง layout ของโลกใหม่ได้ที่:

```yaml
dimension:
  terrain:
    biome-size: 3072
```

รับค่า 1,536–8,192 บล็อก ค่านี้ถูกบันทึกใน `world-layout.yml` เพื่อไม่ให้ขอบไบโอมเลื่อนเมื่อรีสตาร์ตหรือแก้ config ภายหลัง
ไม่ควรลบข้อมูล `terrain` ใน layout ของโลกที่เล่นอยู่ เพราะเป็นทั้งขนาดไบโอมและประวัติพื้นที่ก่อนอัปเกรด

## คำสั่งดูพื้นที่

ผู้เล่นใช้ `/evergarden biome` เพื่อดูชื่อเขตปัจจุบัน ส่วนคำสั่งค้นหาและวาร์ปใช้สิทธิ์แอดมิน:

```text
/evergarden biome locate glacier
/evergarden biome locate ancient-forest
/evergarden biome locate lunar-city
/evergarden tp glacier
/evergarden tp ancient-forest
/evergarden tp lunar-city
/evergarden tp gardens
```

คำสั่ง locate ค้นจาก seed และพิกัดโดยไม่สร้าง chunk ส่วน tp โหลด chunk จุดหมายแล้วตรวจจุดยืนจริงก่อนวาร์ป
คำสั่งเดิม `/evergarden tp garden` ยังเป็นสวนแขวน; `gardens` เป็นไบโอมสวนขนาดใหญ่

## การตรวจสอบและภาพพรีวิว

`tests/biome-world/run.py` ตรวจแผนที่ตัวอย่าง 16×16 กิโลเมตร ความต่อเนื่องของระดับพื้น
พื้นที่น้ำแข็ง สัดส่วนพื้นต่อเนื่อง และประวัติพื้นที่เก่า จากนั้นทดสอบบน Paper จำลองสองรอบ
เพื่อเทียบวัสดุจริง การเจนข้ามขอบ chunk ลำดับการเจน โครงสร้างเดิม การลอย/เชื่อมฐาน และบล็อกที่แก้ไว้หลังรีสตาร์ต

รุ่นส่งมอบผ่าน **73 checks**: ตัวเจนแบบพิกัด 25 ข้อ และ Paper สองรอบ 34 + 14 ข้อ
รวมแหล่งน้ำ 192 บล็อกที่ไม่มีทางรั่ว และลานเมืองที่เชื่อมข้ามช่องว่างธรรมชาติ 159 คอลัมน์
การทดสอบโครงสร้างเพิ่มความหายากในโลกจำลองเป็น 0.30 เพื่อครอบคลุมทุกแบบ โดยไม่ได้แก้อัตราในไฟล์ส่งมอบ

```text
python tests/biome-world/run.py --garden-jar <jar> --classpath-file <classpath.txt> --output <output> --template <cached-paper> --server <new-disposable-server>
python tools/preview_biome_world.py <output>/samples --output-dir previews/biome-world
```

ภาพแผนที่อ่านพิกัดจากตัวเจนจริง ส่วนภาพบล็อกอ่านบล็อกที่เจนจริงและจำลองมุมกล้องกับแสง
ภาพเหล่านี้เป็นพรีวิวจากข้อมูลเกม ไม่ใช่ภาพหน้าจอ Minecraft
ภาพบล็อกเป็นพื้นที่ตัวอย่าง 128×128 บล็อกที่ตัดให้เห็นชั้นวัสดุด้านข้าง ขอบสี่เหลี่ยมในภาพคือขอบเขตตัวอย่าง
ไม่ใช่ขอบของไบโอมจริงซึ่งต่อเนื่องออกไปอีกหลายพันบล็อก
