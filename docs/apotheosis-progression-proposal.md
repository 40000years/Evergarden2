**Apotheosis: ข้อค้นพบและข้อเสนอสำหรับ Evergarden / Advance Magic**

ค้นคว้า 1 พฤศจิกายน 2026 เป็นข้อเสนอการออกแบบ ยังไม่ได้เปลี่ยนระบบเกม ตัวเลขและชื่อใหม่ทั้งหมดด้านล่างเป็นต้นแบบสำหรับทดสอบ

ขอบเขตที่ผู้ใช้ยืนยัน: ใช้โต๊ะ Enchant แบบ Vanilla ไปก่อน คงขั้นตอนการใช้งานที่ผู้เล่นคุ้นเคย และไม่เพิ่ม Eterna / Quanta / Arcana หรือการจัดชั้นหนังสือแบบ Apothic Enchanting ในระยะนี้ ข้อเสนอ Affix, Salvage, Reforge และส่วนอื่นด้านล่างยังเป็นแนวทางให้พิจารณา การตัดสินใจนี้ไม่ได้สั่งถอด Limit Break, Unique Enchant หรือ Gem เดิม

**สิ่งที่ยืนยันจากผู้พัฒนา**

Apotheosis มีหลายสายเวอร์ชัน หน้าโปรเจกต์แยกสาย 1.20.1, 1.21.1 และ 26.1.2 ส่วนชื่อ Apotheosis ในรุ่นใหม่เน้นระบบ Adventure ขณะที่ Enchanting และ Spawners มีโปรเจกต์แยก อ้างอิง [หน้าโปรเจกต์ผู้พัฒนา](https://www.curseforge.com/minecraft/mc-mods/apotheosis) และ [changelog](https://github.com/Shadows-of-Fire/Apotheosis/blob/26.1/changelog.md)

| ระบบ | ข้อค้นพบ | ประโยชน์ที่คาดว่าจะเกิดกับเรา |
|---|---|---|
| Affix และ Rarity | อุปกรณ์มีคุณสมบัติสุ่ม เกรดกำกับกลุ่มคุณสมบัติและความแรง | ของชนิดเดิมยังมีชิ้นที่เหมาะกับบิลด์ให้ตามหา |
| Salvaging | ย่อยอุปกรณ์เป็นวัสดุตามเกรด | ของซ้ำมีประโยชน์และเป็นต้นทุนการปรับแต่ง |
| Reforging | สุ่มชุดคุณสมบัติใหม่ เลือกจากสามผลลัพธ์ ใช้วัสดุเกรดเป้าหมาย เชื้อเพลิงและ XP | ผู้เล่นมีทางสร้างชิ้นที่ต้องการหลังฟาร์มพอ |
| Augmenting | แก้หรือเพิ่มความแรงของ Affix รายตัวด้วยต้นทุนสูง | มีปลายทางให้พัฒนาชิ้นที่เกือบสมบูรณ์ |
| Gems | ผลของ Gem ขึ้นกับประเภทอุปกรณ์ มีคุณภาพ Purity และบางชนิดจำกัดซ้ำต่อชิ้น | เพิ่มทางเลือกจัดบิลด์และเป้าหมายการสะสม |
| World Tiers | ปลดล็อกระดับความยากเพื่อเจอศัตรูและลูตที่ดีขึ้น | เชื่อมความก้าวหน้าผู้เล่นกับรางวัล |
| Invaders / Elites | ศัตรูพิเศษเป็นจังหวะพบของดีระหว่างเดินทาง | การสำรวจมีเหตุการณ์ที่น่าหยุดสู้ |

รายละเอียด Reforging ยืนยันจาก [คู่มือในซอร์ส](https://github.com/Shadows-of-Fire/Apotheosis/blob/26.1/src/main/resources/assets/apotheosis/patchouli_books/apoth_chronicle/en_us/entries/adventure/affix_loot/reforging.json) ซึ่งระบุว่าทั้งสามตัวเลือกไม่ได้เรียงความแรง และช่องเพิ่มเติมมีต้นทุนสอง/สามเท่าของฐาน จึงต้องชั่งน้ำหนักผลลัพธ์กับราคา

Gem รุ่นใหม่ใช้ Purity แยกจากเกรดอุปกรณ์: [คู่มือ Gems](https://raw.githubusercontent.com/Shadows-of-Fire/Apotheosis/26.1/src/main/resources/assets/apotheosis/patchouli_books/apoth_chronicle/en_us/entries/adventure/gems/gems.json) การอัปเกรดมักใช้ Gem Dust วัสดุตามเกรด และ Gem คุณภาพเดียวกันอีกชิ้น: [คู่มือ Gem Cutting](https://github.com/Shadows-of-Fire/Apotheosis/blob/26.1/src/main/resources/assets/apotheosis/patchouli_books/apoth_chronicle/en_us/entries/adventure/gems/gem_cutting.json)

World Tiers และ Gem Purity ถูกเพิ่มในสาย 8.0.0 ส่วนชื่อ Boss/Miniboss เปลี่ยนเป็น Invader/Elite ดู [changelog 8.0.0](https://github.com/Shadows-of-Fire/Apotheosis/blob/26.1/changelog.md#800) สูตรของม็อดแพ็กอาจเปลี่ยนจากค่าโปรเจกต์หลัก

Enchanting มี Eterna สำหรับพลังเอนชานต์, Quanta สำหรับความสุ่ม และ Arcana สำหรับคุณภาพ/จำนวนเอนชานต์ อีกส่วนที่น่าสนใจคือคลังเก็บสมุดเอนชานต์: [Apothic Enchanting](https://www.curseforge.com/minecraft/mc-mods/apothic-enchanting) ส่วนการย้ายและปรับเครื่องเกิดมอนเป็นระบบอีกชุด: [Apothic Spawners](https://www.curseforge.com/minecraft/mc-mods/apothic-spawners)

**วิเคราะห์ว่าทำไมวงจรนี้น่าจะสนุก**

ข้อสรุปส่วนนี้เป็นการวิเคราะห์ของเรา: การดรอปเปิดคำถามหลายข้อพร้อมกัน เช่น ฐานอุปกรณ์ใช่หรือไม่ คุณสมบัติเข้าบิลด์หรือไม่ และค่าสุ่มดีพอหรือยัง ของที่ไม่ใส่ยังเปลี่ยนเป็นต้นทุนสร้างของได้ ส่วนชิ้นที่ดีเกือบครบทำให้มีเป้าหมายระยะยาวผ่าน Augmenting

ผู้เล่นจึงมีทั้งความประหลาดใจจากการพบของ และอำนาจตัดสินใจว่าจะเก็บ ย่อย ขาย หรือพัฒนาต่อ การอัปเกรด +1 อย่างเดียวให้ความรู้สึกการเติบโต แต่ Affix ทำให้เกิดทางเลือกของบิลด์ด้วย

**ฐานของโปรเจกต์เรา**

- [Vault](vault-balance.md) มี Tier I–V และอุปกรณ์ธรรมดาที่ติดเอนชานต์หนึ่งชนิด เหมาะกับการเพิ่มชั้น Affix ในผลรางวัลอุปกรณ์ โดยรักษาจำนวนรางวัลต่อการเปิด
- [อาวุธ Rare / Legendary](vault-weapon-drops.md) มีโมเดลและโรงงานสร้างไอเท็มอยู่แล้ว สามารถใช้ฐานเดิมสร้างความหลากหลายของชิ้นดรอป
- [Limit Break](vault-balance.md) รับผิดชอบระดับเอนชานต์ ส่วน [Unique Enchant](unique-enchant-compatibility.md) รับผิดชอบพลังพิเศษและกลุ่มขัดกัน
- [Staff Gems](staff-gems.md) มีสองช่อง ถอดเปลี่ยนได้ และมี Damage/Cooldown/Max อยู่แล้ว การขยาย Gem ควรต่อจากข้อมูลและช่องเดิม
- [Seraph / Revenant](armor-combat.md) มีโบนัสชุดแรงอยู่แล้ว เช่น ตัวคูณโจมตีและดูดเลือด จึงต้องวัดพลังรวมก่อนเปิด Affix เต็มรูปแบบบนชุดเหล่านี้
- RealmRewards ให้รางวัลตามฝั่ง Nether/End แต่ยังมีพื้นที่ออกแบบรางวัลและวัสดุที่ผูกกับบอสแต่ละตัวโดยตรง

**ข้อเสนอแกนแรก: วงจรของดรอปที่ทำงานครบ**

ดรอปอุปกรณ์ → ตรวจ Affix → ใส่/ขาย/ย่อย → ได้วัสดุ → รีฟอร์จเลือกผลลัพธ์ → เก็บชิ้นที่เข้าบิลด์ → แต่งรายบรรทัดเมื่อถึงช่วงท้าย

เริ่มกับอุปกรณ์ทั่วไปและอาวุธ Rare ที่เลือกไว้ก่อน ใช้โมเดลเดิม ส่วนอาวุธ Legendary และเกราะบอสเข้าระบบภายหลังเมื่อวัดผลร่วมกับพลังเฉพาะตัวแล้ว

แยกเกรด Affix I–V ออกจากหมวดอาวุธ Rare/Legendary เพื่อไม่ทำให้ตัวตนของ Excalibur และอาวุธตำนานอื่นเปลี่ยนไปเพียงเพราะสุ่มเกรด ชื่อไอเท็มเดิม โมเดล เอนชานต์ Limit Break และ Unique Enchant ต้องเดินทางไปกับชิ้นเดิม

| ส่วน | ต้นแบบที่เสนอ |
|---|---|
| Affix | เริ่มประมาณ 12–16 ชนิด แยกตามช่องและสายประชิด/ระยะไกล/เวท/ป้องกัน |
| จำนวนคุณสมบัติ | ช่วงต้นหนึ่งบรรทัด ช่วงกลางสอง ช่วงสูงสาม พร้อมงบพลังของแต่ละเกรด |
| Socket | ช่วงต้นไม่มี ช่วงกลางหนึ่ง ช่วงสูงสอง; คทาใช้สองช่องเดิม |
| Reforge | เห็นสามผลลัพธ์และต้นทุนก่อนเลือก ผลลัพธ์คงเดิมเมื่อปิดเปิดเมนู |
| Salvage | ย่อยแล้วคืนวัสดุน้อยกว่าต้นทุนสร้างชิ้นระดับเดียวกัน คืน Gem ก่อน และแสดงสิ่งที่จะสูญเสีย |
| Augment | เลือกปรับทีละบรรทัด มีเพดานตามเกรดและต้นทุนสูงขึ้นเมื่อเข้าใกล้ค่าสูงสุด |

ตัวเลขสำหรับการทดลองช่วงแรกอาจเริ่มโบนัสเชิงรุกเล็กระดับ 2–4% ต่อบรรทัด และพลังชีวิตเป็นหน่วย HP ขนาดเล็ก ต้องกำหนดเพดานรวมทั้งชุดก่อนเปิดใช้ ตัวเลขเหล่านี้ยังไม่ใช่ค่าที่พิสูจน์ว่าสมดุล

Affix ด้านดูดเลือด รีเซ็ตคูลดาวน์ โจมตีซ้ำ และเจาะเกราะควรเข้าชุดทดสอบภายหลัง เพราะอาจคูณกับพลังชุด เวทโจมตีหลายครั้ง และ Unique Enchant ที่มีอยู่แล้ว

**Gem ที่ควรต่อยอด**

คุณภาพของ Gem ทำให้ชิ้นซ้ำมีทางพัฒนา แต่ต้องคงผลของ Gem เก่าที่ผู้เล่นได้มาแล้ว การเปลี่ยนข้อมูลต้องไม่ลดโบนัสของเก่าโดยอัตโนมัติ

ตัวอย่าง Gem ใหม่แบบออกแบบเฉพาะเรา: หินสายไฟใส่ดาบเพิ่มประสิทธิภาพต่อเป้าหมายติดไฟ ใส่เกราะช่วยด้านไฟ ใส่คทาเสริมเวทไฟ เป็นการตัดสินใจว่าจะเอาทรัพยากรชิ้นเดียวไปลงส่วนไหนของบิลด์

ช่วงแรกควรทำคลัง Gem พร้อมกรองตามอุปกรณ์ที่เลือก และหน้าเปรียบเทียบค่ารวมก่อนใส่ การจัดของจะมีความสำคัญเมื่อ Gem มีหลายคุณภาพ

**ศัตรูและความยากที่เหมาะกับเซิร์ฟเวอร์ร่วมกัน**

เริ่ม Elite/Champion จากมอนเดิม ใส่ออร่า ชื่อ และความสามารถอ่านออกหนึ่งถึงสองอย่าง เช่น โล่เป็นจังหวะ หรือพื้นอันตรายที่มีสัญญาณนำ ให้ชิ้น Affix อย่างน้อยหนึ่งชิ้นกับผู้ร่วมสู้ที่ผ่านเงื่อนไข และมีโอกาสได้ Gem

เกณฑ์ผู้ร่วมสู้ควรครอบคลุมความเสียหายและการสนับสนุนตามระบบที่เลือก พร้อมจำกัดการเกิดตามพื้นที่ การฟาร์มจาก spawner และการเกิดซ้ำ ต้องไม่ให้ศัตรูได้รับการปรับค่าสถานะซ้อนจาก LevelledMobs; โปรเจกต์มีตัวช่วย compat สำหรับมอนที่ Evergarden ดูแลอยู่แล้ว

นำแนวคิด World Tier มาเริ่มกับระดับดันเจียนหรือภารกิจท้าทายที่ผู้เล่นเลือกเข้า และใช้ความสำเร็จส่วนบุคคลปลดล็อก การเพิ่มความยากควรอยู่ในพื้นที่กิจกรรมนั้น ผู้เล่นใหม่ที่อยู่ในโลกเดียวกันจึงยังมีเส้นทางเล่นของตน

Vault Tier และความก้าวหน้าผู้เล่นต้องกำหนดความสัมพันธ์ให้ชัดก่อนเพิ่มระบบระดับใหม่ มิฉะนั้นจะมี Tier หลายชุดที่อธิบายยาก

**การแจกบทบาทให้ระบบเดิม**

| ระบบ | หน้าที่ที่เสนอ |
|---|---|
| วัสดุฐานและชนิดอาวุธ | รูปแบบโจมตีและการใช้งาน |
| เกรด / Affix | ค่าสุ่มและแนวถนัดของชิ้นนั้น |
| Enchant / Limit Break | เอนชานต์และสิทธิ์ระดับเหนือปกติ |
| Unique Enchant | ความสามารถพิเศษหลักและกฎขัดกัน |
| Gem | ช่องปรับบิลด์ที่เปลี่ยนได้ |
| อาวุธตำนาน / เกราะบอส | ตัวตนเฉพาะและเป้าหมายหลักจากบอส |

การหลอม +1 ถึง +5 จากข้อเสนอก่อนหน้านี้ควรรอให้วงจร Affix ชัดก่อน หาก Augmenting ทำหน้าที่พัฒนาค่าสุ่มครบอยู่แล้ว ก็อาจไม่ต้องเพิ่มขั้นหลอมอีกชุด

**ลำดับพัฒนา**

1. Affix + ข้อมูลบนไอเท็ม + ของดรอปจาก Vault + Salvage + Reforge พร้อมเมนูเปรียบเทียบ เป็นวงจรใช้งานได้ครบ
2. Gem สำหรับอุปกรณ์ + การรวมคุณภาพ + คลัง Gem โดยใช้ช่องคทาเดิมและรักษาของเก่า
3. Elite/Champion และวัสดุเฉพาะบอส เพื่อให้การสำรวจและการเลือกแหล่งฟาร์มมีเป้าหมาย
4. Augmenting และภารกิจความยากสูง สำหรับผู้เล่นที่ได้บิลด์หลักแล้ว

โต๊ะ Enchant คงแบบ Vanilla ตามขอบเขตที่ยืนยันแล้ว ส่วน Spawner ที่ปรับได้เก็บเป็นแนวคิดแยกภายหลัง การเริ่มพัฒนาควรให้ผู้เล่นเข้าใจการดู Affix ย่อยของ และรีฟอร์จผ่านเมนูช่างก่อนเพิ่มขั้นตอนอื่น

**ความเป็นไปได้ทางเทคนิค**

ระบบไอเท็มและการต่อสู้ทำเป็นปลั๊กอิน Paper ร่วมกับ resource pack และเมนู Java/Bedrock ได้ โดยไม่ต้องย้ายเซิร์ฟเวอร์ไปใช้ตัวม็อด Forge/NeoForge หน้าต่างเฉพาะและปุ่มลัดของม็อดต้องออกแบบเป็นเมนูที่ไคลเอนต์เดิมรองรับ

ควรมีตัวรวมโบนัสอุปกรณ์จุดเดียว แยกแหล่งโบนัสและกลุ่มขัดกัน บันทึก Affix/Gem เป็นข้อมูลมีเวอร์ชัน และใช้กระบวนการจ่ายวัสดุ/รับผลลัพธ์ที่ไม่ให้ของซ้ำเมื่อปิดเมนู วาร์ป หรือกระเป๋าเต็ม การวัดสมดุลต้องรวม Seraph/Revenant, Skill Tree, Gem, Unique Enchant และเวทหลายฮิตในสถานการณ์เดียวกัน

ข้อเสนอนี้เป็นการนำหลักการมาออกแบบระบบของเราเอง ชื่อ ภาพ และทรัพยากรควรสร้างสำหรับ Evergarden โดยตรง
