# คทาธาตุจากสมบัติ

Advance Magic **1.17.0-loot-only-staffs** และ Evergarden **3.0.0-e2.97-elemental-staff-loot**

คทาธาตุทั้ง 8 แบบคราฟไม่ได้อีกต่อไป สูตรเก่าถูกนำออกจากเซิร์ฟเวอร์และสมุดสูตรของผู้เล่น พร้อมปิดผลลัพธ์คทาผ่านโต๊ะคราฟและ Crafter คทาที่ผู้เล่นมีอยู่ยังใช้ได้ตามเดิม การประทับเวทและอัปเกรดระดับคทายังใช้ระบบเดิม

| แหล่ง | โอกาสได้คทา | วิธีสุ่ม |
| --- | --- | --- |
| Evergarden Vault | 10% ต่อการรับรางวัลที่มีสิทธิ์ | เป็นรางวัลหลัก 1 ชิ้น ส่วนอีก 90% ใช้สัดส่วนรางวัลเดิม |
| กล่อง Whale / Observatory / Hanging Garden ในมิติ Evergarden | 3% ต่อกล่อง | เพิ่มได้สูงสุด 1 คทาในกล่องที่เพิ่งแจกสมบัติครั้งแรก |
| กล่องโครงสร้าง Evergarden ในโลกปกติ | 1% ต่อกล่อง | โครงสร้าง Sanctuary ของปลั๊กอินในโลก NORMAL ที่ไม่ใช่มิติ Evergarden |

เมื่อสุ่มได้ จะเลือกหนึ่งใน Fire, Water, Ice, Wind, Earth, Light, Dark และ Lightning ด้วยโอกาสเท่ากัน คทาเป็น **Apprentice มีช่องเวทว่าง 3 ช่อง** พร้อมรหัสไอเท็มเฉพาะ ต้องหาคัมภีร์มาประทับตามเดิม

Vault ยังใช้กุญแจและสิทธิ์เปิดหนึ่งครั้งต่อผู้เล่น/สถานที่เดิม กล่องสมบัติเป็นของร่วมกันของผู้เล่นที่สำรวจกล่องนั้น ไม่ได้สุ่มแยกต่อคน กล่องในโลกปกติของ Minecraft ที่ไม่ได้สร้างโดย Evergarden ไม่ได้รับคทาจากระบบนี้

กล่องที่แจกของไปแล้วไม่ถูกเติมย้อนหลัง การสุ่มกล่องสำเร็จหรือพลาดถือเป็นครั้งสุดท้าย รวมถึงกรณีกล่องเต็ม ปิดระบบดรอป หรือ Advance Magic ไม่พร้อม กล่องถูกเปิดซ้ำ โหลด chunk ใหม่ หรือถูกรื้อแล้ววางใหม่ก็ไม่สุ่มซ้ำ รางวัลอื่นใช้กระแสสุ่มเดิม จึงไม่เปลี่ยนตามการเพิ่มคทาในกล่อง

## ตั้งค่า

ค่าใน `plugins/Evergarden/config.yml` หากยังไม่มีจะใช้ค่าเริ่มต้นนี้:

```yaml
staff-loot:
  enabled: true
  vault-chance: 0.10
  sky-chest-chance: 0.03
  overworld-chest-chance: 0.01
```

ค่าเป็นสัดส่วน 0–1 การปรับค่ามีผลกับการสุ่มครั้งถัดไป ไม่เพิ่มของในกล่องที่เคยแจกแล้ว คทาบิน คทาฟื้นฟู และอาวุธชนิดอื่นใช้แหล่งหาเดิม

## ติดตั้ง

1. ปิดเซิร์ฟเวอร์แล้วแทน `advance-magic.jar` และ `evergarden.jar` ด้วยไฟล์ทั้งสองจากชุด `elemental-staff-loot-1.17.0.zip` อย่าใส่ JAR เก่าและใหม่ซ้ำในโฟลเดอร์ plugins
2. เปิดเซิร์ฟเวอร์ใหม่ สูตรคทาธาตุถูกถอดอัตโนมัติ ค่าอัตราดรอปใช้ค่าเริ่มต้นได้โดยไม่จำเป็นต้องลบ config เก่า
3. Resource pack และเอฟเฟคระดับสูงจากรุ่น 1.16.0 ยังฝังอยู่ใน JAR เวอร์ชัน Bedrock pack ยังเป็น 2.17.0 เพราะไม่ได้เปลี่ยนภาพ

ผลทดสอบและ SHA-256 ของ JAR ที่ตรวจจริงบันทึกใน `elemental-staff-loot-manifest.json` ภายในชุดติดตั้ง

## ผลตรวจรุ่นนี้

- Paper ตรวจระบบเวทและการคราฟ **1,501 ข้อผ่าน** รวมสูตรเก่าทั้ง 8 แบบ สมุดสูตร สูตรชื่ออื่น ผลลัพธ์ที่ถูกแทน และ Crafter อัตโนมัติ
- Evergarden + Geyser/Floodgate ตรวจสมบัติ **513 ข้อผ่าน** รวมขอบเขตอัตราดรอปตรง 10% / 3% / 1%, ครบทั้ง 8 ธาตุ, การสร้างกล่องจริงทั้งสามสถานที่, Sanctuary ครั้งแรก, กล่องเต็ม และการกันเติมซ้ำ
- ไฟล์ภาพ Java/Bedrock และแพ็กที่ฝังใน Advance Magic JAR **1,261 ข้อผ่าน**

ทดสอบบน Paper localhost แยกจากเซิร์ฟเวอร์ที่มีผู้เล่น ยังไม่ได้ติดตั้งลงเซิร์ฟเวอร์จริง
