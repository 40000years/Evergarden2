# แผนคร่าว ๆ: ไม้เท้าบิน Evergarden2

สถานะ: **ระบบเล่นจริงและการรวมแพ็กเสร็จในโค้ดแล้ว** ผ่านการทดสอบ Paper แบบแยก; ยังรอตรวจภาพและการบังคับกับ client Java/Bedrock จริง ดู [วิธีใช้และผลตรวจ](flying-staff-implementation.md)

## ภาพที่ต้องการ

ไม้เท้าหนึ่งชนิดสำหรับผู้เล่นทั่วไป ใช้ลอยตัวสร้างบ้านหรือฟาร์มได้ ผู้เล่นนั่งบนด้ามไม้เท้า คลิกขึ้นขี่คล้ายเรือ บินช้ากว่าปีกและใช้มานาต่อเนื่อง ใช้พาหนะเฉพาะของระบบ ไม่ใช้ Boat เป็นฐานหรือแก้โมเดลเรือ vanilla

รูปลักษณ์ต้นแบบ: ด้ามไม้เข้ม ปลอกทอง ที่จับน้ำเงินเข้ม คริสตัลมินต์อยู่ในวงแหวนทอง ปลายท้ายมีประกายสั้น ๆ ตรงกลางเว้นพื้นที่สำหรับท่านั่ง ใช้โมเดลเดียวสำหรับทั้ง Java และ Bedrock โดยปรับตำแหน่งการถือ/สวมของแต่ละ client

## สิ่งที่ทำแล้ว

- [ต้นฉบับ resource pack และคู่มือ](../advance-magic/art/flying-staff/README.md): โมเดล Java, geometry/attachables ของ Bedrock, textures และ Geyser mapping
- แอนิเมชัน `summon`, `idle`, `flight`, `dismiss` พร้อมท่าถือไอเทม
- Java: แสงคริสตัลเป็น animated texture; เตรียมเฟรมท่าขยับไว้ให้ระบบในอนาคตเลือก
- Bedrock: มี bone animations กับเอฟเฟกต์ประกายและหางมินต์ ผูกกับ attachable ของแต่ละสถานะ
- รวมงานภาพใน `advance-magic/dist` และ JAR ใช้ Bedrock pack/mapping ฉบับเดียวกับคทาเดิม Java เสิร์ฟแพ็กใหม่ที่ฝังใน JAR พร้อม SHA-1 จากไฟล์จริง
- เพิ่มไอเทม สูตรคราฟต์ `/magic givestaff` ระบบเรียก/ขึ้นขี่/เก็บ ขับเฟรมบน Java และหักมานาระหว่างขี่

ผู้เล่นยังต้องมีปลั๊กอิน Advance Magic รุ่นใหม่ร่วมกับแพ็กใหม่; การโหลดแพ็กอย่างเดียวไม่เพิ่ม gameplay

## การใช้งานที่วางไว้

1. ถือไม้เท้าแล้วคลิกขวา: เรียกออกมาด้านหน้าประมาณ 1–2 บล็อก เมื่อมีที่ว่างและผู้เล่นอยู่ในเขตที่อนุญาต
2. คลิกขวาที่ไม้เท้า: เจ้าของขึ้นนั่งกลางด้าม กล้องและตำแหน่งนั่งต้องไม่บังการวางบล็อก
3. ขณะขี่: เคลื่อนที่และลอยค้างได้ ใช้มานาต่อเนื่องแม้หยุดอยู่กับที่ เพื่อช่วยงานก่อสร้าง
4. เปลี่ยนไปถือบล็อกหรือเครื่องมือระหว่างขี่ได้ การคลิกบล็อกยังทำงานตามปกติ
5. ลงจากไม้เท้าแล้วตีตัวไม้เท้าเพื่อเรียกเก็บ มีเพียงภาพพาหนะที่หายไป ไอเทมต้นฉบับยังอยู่กับเจ้าของและไม่ดรอปซ้ำ
6. มานาใกล้หมด: เตือนก่อนหมด เมื่อหมดให้ลดระดับลงอย่างควบคุมได้และจบการขี่โดยปลอดภัย

เรียกได้คนละหนึ่งอัน สูตรที่ใช้: `GAG / BRB / GAG` โดย `G` คือ Gold Ingot, `A` คือ Amethyst Shard, `B` คือ Blaze Rod, `R` คือ Heart of the Sea

## แอนิเมชันที่เตรียม

| สถานะ | เวลา | ภาพที่ต้องการ | การเชื่อมต่อในอนาคต |
| --- | --- | --- | --- |
| `held` | ค้าง | ไม้เท้าขนาดถือมือ | ไอเทมของผู้เล่น |
| `summon` | 0.6 วินาที | ขยายขึ้นจากจุดเล็ก ดีดเบา ๆ พร้อมประกายทอง | จบแล้วเปลี่ยนเป็น `idle` |
| `idle` | วน 3.2 วินาที | ลอยขึ้นลงเล็กน้อย คริสตัลและวงแหวนมีชีวิต | รอขึ้นขี่ |
| `flight` | วน 1.6 วินาที | สั่นไหวเล็กน้อย มีประกายมินต์ท้ายด้าม | ระบบเปิดเฉพาะตอนขี่ |
| `dismiss` | 0.4 วินาที | ย่อกลับเป็นจุดแสง | จบแล้วลบตัวแสดง |

Bedrock มีวงแหวนหมุนและคริสตัลเต้นด้วย bone animation ส่วน Java ต้นแบบมีเฟรมสำหรับขยับทั้งไม้เท้าและแสง texture ยังไม่มีวงแหวนหมุนแยกชิ้น การขยับของ resource pack เป็นเพียงภาพ ไม่ได้ย้าย hitbox หรือที่นั่งตามไปด้วย

## ขั้นที่ทำในโค้ดแล้วและงานตรวจในเกม

1. **ขี่:** ใช้ Armor Stand ที่มองไม่เห็น เป็นทั้งที่นั่งและตัวแสดงภาพ มี tag เจ้าของและไม่บันทึก entity ลงโลก ท่านั่งและระดับโมเดลต้องตรวจบน client จริง
2. **ควบคุม:** อ่าน input ผ่าน Paper แล้วขยับตัวพาหนะโดยความเร็วจำกัด ช่วงลอยค้างได้ ปุ่มกระโดดขึ้น มองลงแล้วเดินหน้าเพื่อลงระดับ ปุ่มย่องสั่งลงจอดก่อนลงจากพาหนะเมื่ออยู่สูง ต้องตรวจบนมือถือจริง
3. **มานา:** ใช้ `ManaService`/`CastAccount` หัก 2 มานา/วินาทีโดยค่าเริ่มต้น พักการฟื้นมานาระหว่างขี่ มีเตือนมานาใกล้หมดและลงจอดเมื่อหมด ค่าปรับใน config
4. **ภาพ:** ปลั๊กอินสลับ item model ตามสถานะและขับเฟรม Java; Bedrock ใช้ animation clips ของ attachable ในแพ็ก สั่ง particle vanilla เพิ่มเล็กน้อยจากเซิร์ฟเวอร์
5. **เก็บงาน:** ตรวจพื้นที่โล่ง ขอบโลกและ chunk ที่โหลดอยู่ จำกัดไม้เท้าคนละหนึ่งตัว ลบเมื่อออกเกม ตาย ย้ายโลก ปิดปลั๊กอิน หรือไอเทมหาย ผู้เล่นยังอยู่ใต้การป้องกันการวาง/ทุบบล็อกของปลั๊กอินอื่น
6. **แพ็ก:** รวม source ใน build เดิม Bedrock pack version `1.4.0` มี mapping ใหม่ในไฟล์เดิม Java bundle เสิร์ฟจากพอร์ต 8187 ตามค่าเริ่มต้น

ยังไม่มีระบบเลเวลหรือ dependency ใหม่ ใช้ scheduler กลางและหนึ่งตัวแสดงต่อคน แพ็กภาพเพิ่มขนาด JAR เพียงตามสินทรัพย์ที่เพิ่ม

## เกณฑ์ก่อนเปิดให้ผู้เล่น

- Java และ Bedrock เห็นไม้เท้า ท่านั่ง และการขึ้นลงถูกต้อง รวมถึงผู้เล่นคนอื่นที่มองอยู่
- เคลื่อนที่ไม่กระตุก ผ่านสิ่งกีดขวางไม่ได้ และวางบล็อก/ใช้เครื่องมือจากที่นั่งได้จริง
- มานาลดสุทธิจริงแม้ผู้เล่นมีค่าฟื้นมานาสูง; มานาหมดแล้วไม่ทำให้ร่วงตายทันที
- เก็บไม้เท้าและออกเกมแล้วไม่มี entity ค้างหรือไอเทมเพิ่ม
- ตรวจปฏิสัมพันธ์กับระบบ double jump, anti-cheat และ protection ที่เซิร์ฟเวอร์ใช้

## ข้อจำกัดที่ยังต้องทดสอบ

ทดสอบระบบกับ Paper `allow-flight=false` แล้ว แต่ยังไม่ได้เปิดแพ็กนี้ใน client จริง ท่าถือ ระดับที่นั่ง ความลื่น การส่งโมเดลผ่าน Geyser การรีเซ็ตแอนิเมชันและพาร์ติเคิลบน Bedrock จึงยังรอการทดสอบจริง

Java resource pack ไม่สั่ง logic การขี่หรืออ่านสถานะมานาเอง ส่วน Geyser ต้องมี Bedrock pack และ mapping ตาม [เอกสาร Custom Items](https://geysermc.org/wiki/geyser/custom-items/) การทดสอบ Paper ยืนยัน server-side mount กับมานา แต่ไม่ยืนยันการแสดงผลหรือการควบคุมจาก client จริง
