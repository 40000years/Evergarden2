## /spell: หน้าเดียวจบ

| แถว | มีอะไร |
| --- | --- |
| บน | วิธีใช้ · ป้องกันกดทิ้ง · Skill Tree · อัปเกรดคทา · สมุดรวมเวท · ปิด |
| 2 | คทาในมือ แล้วตามด้วยช่องเวท 5 ช่อง (ว่าง = กรอบประ · ยังไม่ปลดล็อก = กุญแจ) |
| 3 | ปุ่มส้ม **ถอด** ใต้เวทแต่ละช่อง |
| 4 | ปุ่มฟ้า **เลื่อนไปซ้าย** |
| 5-6 | **คัมภีร์ในกระเป๋า** ขึ้นมาให้เอง ตัวที่ใส่ได้อยู่ก่อน |

- **ใส่เวท:** คลิกคัมภีร์ (แถวล่าง หรือในกระเป๋าตัวเองก็ได้) เวทลงช่องว่างแรกทันที
- **คทาเต็ม:** คลิกคัมภีร์ แล้วคลิกเวทที่จะเอาออก ได้คัมภีร์เวทเก่าคืนอัตโนมัติ
- **ถอด:** กดปุ่มส้มครั้งเดียว ได้คัมภีร์คืน (ต้องมีที่ว่างในกระเป๋า)
- **เลือกเวทที่ร่าย:** คลิกเวทในคทา เวทที่ใช้อยู่มีประกาย
- **อัปเกรด:** ปุ่มบอกวัตถุดิบที่มี/ที่ต้องใช้ทีละอย่าง (✔/✖) กด 2 ครั้งเพื่อยืนยัน
- คัมภีร์ที่ใส่ไม่ได้บอกเหตุผลตรงๆ (ต้องอัปเกรดคทา / มีเวทนี้แล้ว)
- ไม่มีขั้นตอนไหนที่ทำให้เวทหาย จึงไม่ต้องมีหน้ายืนยัน
- พิมพ์ `/spell` ตอนไม่ได้ถือคทา ระบบจะหยิบคทาจากแถบด่วนให้
- `/spell imprint` และ `/spell extract` เปิดหน้าเดียวกัน · `/spell extract <ช่อง>` ถอดทันที

## /pets

- **คอก:** รูปสัตว์จริงตามร่าง (เด็ก/กลาง/โต · กรอบเขียว/ฟ้า/ทอง) · ปุ่มบน: วิธีใช้+อาหารที่ชอบ · เรียก/เก็บตัวที่ติดตาม · รัง (ไอคอนเปลี่ยนเป็นนาฬิกา/ไข่ตามสถานะ) · ซ่อนสัตว์คนอื่น
- **การ์ดสัตว์:** วงแหวนความผูกพัน / การเติบโต / พลังชีวิต · สกิล · ค่าพลัง · ปุ่มเรียก ตั้งชื่อ **ผสมพันธุ์ · หาคู่** ปล่อย (กด 2 ครั้ง) · โหมด 4 ปุ่ม (อันที่ใช้อยู่สีทอง)
- **รังผสมพันธุ์ (หน้าเดียว):**
  - ด้านบนเป็นคู่ที่เลือก คลิกตัวที่เลือกแล้วเพื่อเอาออก ปุ่มกลางเริ่มผสม เก็บไข่ หรือบอกว่ายังขาดอะไร
  - แถวเงื่อนไข เขียว ✔ / แดง ✖ / เทา (ยังเลือกไม่ครบ) ได้แก่ โตเต็มวัย · ชนิดเดียวกัน · ความผูกพัน 50 · ไม่ติดพัก · โควตาไข่วันนี้ · อาหาร (โชว์ไอเท็มจริงพร้อมจำนวนที่มี)
  - ด้านล่างเป็นสัตว์ทั้งคอก ตัวที่เลือกได้สีปกติ ตัวที่เลือกไม่ได้เป็นสีเทาพร้อมเหตุผล
  - ปุ่ม "ผสมพันธุ์" ในการ์ดสัตว์ เปิดรังพร้อมเลือกตัวนั้นไว้แล้ว · `/pet nest` เปิดรังตรงๆ
- **Bedrock (ฟอร์ม):** ปุ่มมีรูปสัตว์/ไอคอน · หน้ารังแสดงเช็กลิสต์ ✔/✖ · หน้าเลือกคู่บอกว่าตัวไหนเลือกไม่ได้เพราะอะไร

กติกาผสมพันธุ์ ฟักไข่ โหมด และการตั้งชื่อเหมือนเดิมทุกอย่าง

## ไฟล์

- `tools/menu_gui_assets.py`: เท็กซ์เจอร์ 191 ชิ้น (ปุ่ม, รูปสัตว์ 17 ชนิด × 3 ร่าง + แบบสีเทา) จาก `dist/evergarden-pet-preview.zip`
- `advance-magic/.../elemental/SpellMenu.java` (เขียนใหม่) · `StaffSpellService.swap()` และ `scrollIcon()` (ใหม่)
- `evergarden/.../pet/PetMenu.java`: เมนูกล่องเขียนใหม่ ฟอร์ม Bedrock ปรับหน้ารัง/เลือกคู่
- รูปในเมนูสัตว์อยู่ในแพ็ก Advance Magic (`advance_magic:menu_*`) ถ้าไม่ได้ติดตั้ง Advance Magic ปุ่มจะเป็นกระดาษ แต่ใช้งานได้
- สำรองไฟล์ก่อนแก้: `output/menus-20261023/before/`

```powershell
python tools/menu_gui_assets.py                      # ภาพตัวอย่าง
python tools/build_armor_sets.py --version <ถัดไป>   # ใส่ชุดเกราะ + เท็กซ์เจอร์เมนูทั้งหมดลงแพ็ก dist
python tools/build_plugin_jars.py
```

## ยังไม่ได้ลองในเกม

1. /spell: ใส่เวทจากแถวล่างและจากกระเป๋า · สลับตอนคทาเต็ม · ถอด · เลื่อน · อัปเกรด 2 คลิก
2. /pets: เลือกคู่จากรายการ เริ่มผสม เก็บไข่ ยกเลิกรัง ปล่อยสัตว์ (Java และฟอร์ม Bedrock)
3. Bedrock: ไอคอนในเมนูกล่องและรูปบนปุ่มฟอร์มขึ้นครบ (ถ้าไม่ขึ้น ให้ restart)
