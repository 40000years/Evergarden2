# สัตว์เลี้ยงที่พบได้ใน Evergarden

สัตว์เลี้ยงป่า 32 ชนิดมีโอกาสปรากฏในโลก Evergarden โดยยังไม่เปิดสัตว์เลี้ยงระดับตำนานทั้ง 5 ชนิด ผู้เล่นป้อนอาหารที่ชอบเพื่อเทม เลี้ยงให้โต และผสมพันธุ์ได้ ดู [สัตว์เลี้ยงคู่ใจ](pet-companions.md) ส่วนการขี่ยังไม่รวม

ติดตั้ง [dist/evergarden.jar](../dist/evergarden.jar) รุ่น `3.0.0-e2.128-pet-menagerie` แทน JAR เดิม แล้วรีสตาร์ตเซิร์ฟเวอร์ ให้ผู้เล่นรับ resource pack ใหม่ แพ็ก Bedrock รุ่น 3.54.0 และมี [Seraph ผู้แลกเปลี่ยน](seraph-trader.md) ที่จุดเกิดด้วย

## e2.127: เกิดตามถิ่น · เห็นง่ายขึ้น

- **ถิ่นอาศัย:** แต่ละชนิดพบได้ทุกที่ แต่พบในถิ่นของมันบ่อยกว่า 3 เท่า วัดจากไบโอมตรงจุดเกิด
  - สวน Evergarden: Nine-Tails, Entling, Tortoise, Chrono Fairy
  - ธารน้ำแข็ง: Frost Wyvern, Runic Golem, Tortoise, Manta
  - ป่าโบราณ: Nine-Tails, Astral Owl, Shadow Panther, Entling
  - นครจันทรา: Astral Owl, Cerberus, Gargoyle, Golem, Manta, Mimic
- ชนิดที่ผู้เล่นเพิ่งเจอใน 4 ครั้งล่าสุดมีโอกาสครึ่งหนึ่ง (แทนการสุ่มใหม่ 75% แบบเดิม)
- **ไม่เกิดใต้หลังคา:** จุดที่มีเพดานภายใน 2–7 บล็อก (ถ้ำ ชะง่อนหิน อาคาร) ถูกข้าม ใต้ใบไม้หรือเกาะที่สูงกว่านั้นยังเกิดได้
- **เกิดในสายตา:** 2 ใน 3 ของจุดที่ลองอยู่ในมุม 110° ด้านหน้าผู้เล่น
- **บอกตำแหน่ง:** มีเสียงกระดิ่งผลึกและประกายตรงจุดเกิด และ action bar บอกผู้เล่นว่าอยู่ทางไหนและห่างเท่าไร ปิดได้ที่ `pets.wild-spawns.announce: false`

## e2.116: แก้หน้าไม่ตรงทิศเดิน

- พบว่า Paper หมุน ItemDisplay ที่ขี่ตัวรับเมื่อ teleport พร้อมเปลี่ยนมุม ขณะที่ rig หมุนโมเดลไว้อีกครั้ง จึงดูเดินถอยหลังหลังจากเลี้ยว
- ย้ายตำแหน่งตัวรับโดยเก็บมุมเดิม แล้วตั้งมุมตัวรับแยกจากการย้าย ชิ้นโมเดลจึงรับการหมุนจาก rig เพียงครั้งเดียว ใช้เส้นทางเดียวกันทั้งเดิน บิน และวาร์ป
- การทดสอบบน Paper ตรวจมุม entity และทิศหน้าที่วาดจริงครบ 36 ร่าง ผ่าน 12,255 checks รวมการเลี้ยวข้าม ±180° และนกฮูกเดินตามเจ้าของที่ถอยออกไปหกทิศ รุ่น e2.115 ล้มด้วยการทดสอบเดียวกัน
- ระบบสัตว์เลี้ยงและ Seraph ผ่านซ้ำ 165 checks รวม follow, stay, perch และ assist ยังไม่ได้ตรวจภาพหลังแก้กับไคลเอนต์ที่เชื่อมต่อจริง

## ขัดเกลา Cerberus · Wyvern · Fairy (รวมใน e2.116)

- **Crimson Cerberus:** หัวข้างเล็กลงและหันออกจากหัวกลาง เพิ่มพื้นที่ช่วงอกพร้อมเกราะแดงและสายทองที่มองเห็นได้ชัด
- **Frost Wyvern:** ลำตัวและคอเอนไปข้างหน้าอย่างผ่อนคลาย ปีกมีข้อพับที่ข้อมือ พับเก็บด้านหลังตอนพักและกางออกขณะบิน
- **Chrono Fairy:** ปรับแก้มและคาง ผมปัดข้างที่ไม่แบนเป็นฝาครอบ และรอยยิ้มโค้งขนาดเล็ก คงปีกกับนาฬิกาทรายเดิม
- ปรับรูปทรงเฉพาะสามชนิดนี้ครบเก้าร่าง โมเดล Arkhaia ดาบ บอสอื่น และสัตว์อีก 42 ร่างคงเดิมจาก e2.113

## e2.113: มองตามผู้เล่นและปรับทรงสัตว์ทั้งชุด

- สัตว์ป่ามองตามตำแหน่งปัจจุบันของผู้เล่นที่เห็นในระยะ 8 บล็อก รวมระหว่างพักและช่วงพักทักทาย หัวมองนำแล้วลำตัวค่อยหันตาม จำกัดมุมตามสรีระ เช่น Manta หันหัวได้น้อยกว่านกฮูก
- ตัวติดตามชะลอเมื่อเลี้ยวมุมแคบ หยุดหันก่อนถ้าจุดหมายอยู่ข้างหลัง แล้วเดินไปตามทิศที่ตัวหัน ภาพบน Java และ carrier ของ Bedrock หันตรงกันแม้ยืนอยู่กับที่
- ปรับโมเดลทั้ง 17 ชนิดครบ 51 ร่าง: ลดชั้นทรงเหลี่ยมซ้อน ปรับทรงเฉพาะชนิด และใช้ความละเอียดพื้นผิวสม่ำเสมอ ชื่อชนิดและวัยเดิมใช้ต่อได้
- Manta มีครีบกวาดเรียว ปลายครีบและหางขยับตามเป็นระลอก เห็นหน้าชัดครบทุกวัย; Panther มีช่วงไหล่ เอว สะโพก และขาแบบแมว ลดแผ่นประดับที่บังทรงตัว
- ภาพตรวจโมเดลจาก geometry ที่ส่งจริง: [ดูทั้งชุด](../previews/pet-models/index.html) · [ภาพรวม](../previews/pet-models/pet-collection.png)

## e2.109: แก้หัวและชิ้นส่วนสัตว์หันกลับด้านบน Java

- ชดเชยการหมุน 180° ที่ตัวเกมเพิ่มขณะวาด ItemDisplay เพื่อให้หัว เท้า และหางหันตรงกับข้อต่อและท่าเคลื่อนไหวที่ออกแบบไว้
- ตั้งมุมเริ่มต้นของ ItemDisplay เป็นศูนย์ เพื่อไม่ให้มุมของตัวรับซ้อนกับการหันของโมเดล สัตว์ที่เกิดมาในทิศอื่นจึงหันตรงกับทิศเดิน
- ใช้โมเดล พื้นผิว และ resource pack เดิมทั้งหมด การแก้นี้มีผลกับภาพสัตว์บน Java เท่านั้น

## e2.112: การันตีการพบและตรวจสาเหตุได้

- **การันตีการพบ:** ถ้าอยู่ใน Evergarden ครบ 8 นาทีเกม (`guarantee-minutes`) โดยยังไม่เจอสัตว์ป่า การสุ่มรอบถัดไปจะผ่านแน่นอน ระบบไม่การันตีถ้าตั้งโอกาสเป็น 0
- **`/evergarden pets wild status`:** บอกผลสุ่มล่าสุดของผู้เล่นแต่ละคน เช่น สุ่มไม่ผ่านแล้วการันตีในอีก N นาที, ยังไม่ได้รับแพ็ก World Boss, มีสัตว์ป่าใกล้ตัวครบแล้ว หรือหาพื้นไม่ได้เพราะอะไร
- **บันทึกใน console:** สัตว์ป่าที่เกิดเองถูกบันทึกเป็น `Wild pet <ชนิด>/<วัย> appeared near <ผู้เล่น> at x y z`
- **ทดสอบบนแผนที่จริง:** ผมเดินผู้เล่นจำลองครั้งละ 30 บล็อก 80 จุด ทุกจุดเกิดสัตว์ได้ (80/80) เมื่อบังคับให้การสุ่มผ่าน

## e2.109: การเคลื่อนไหวเป็นธรรมชาติขึ้น

- **เคลื่อนที่ลื่นขึ้น:** ตัดสินใจทุก 5 tick แต่ขยับตัวเล็กน้อยทุก tick สัตว์ที่เดินขยับทุก tick (เดิมขยับเป็นจังหวะเดิน-หยุด ทุก 5 tick)
- **ท่าทางตรงกับ keyframe:** ส่งท่าตามระยะห่าง keyframe ของแต่ละคลิป (ท่าเดินประมาณทุก 2–3 tick) และส่งท่าล่วงหน้า เพื่อให้ไคลเอนต์ถึง keyframe ตรงเวลา ขาไม่ข้ามเฟรมจนดูแข็ง
- **ความเร็วค่อยเป็นค่อยไป:** เร่งขึ้นตอนเริ่มเดิน และชะลอจนหยุดเอง ความเร็วขาและปีกปรับตามความเร็วจริง ทั้ง Java และ Bedrock (pack 3.41.0)
- **การบิน:** บินเป็นเส้นโค้ง เงยหัวขึ้นตอนไต่ ก้มลงตอนดิ่งหรือลงจอด และเอียงตัวเข้าโค้ง

## e2.108: แก้สัตว์ป่าไม่เกิด

- **การเกิดตามธรรมชาติ:** วัดระยะ 24–48 บล็อกเฉพาะแนวนอน และหาพื้นใกล้ระดับที่ผู้เล่นยืน (หรือพื้นใต้ตัวผู้เล่นที่กำลังบิน) แทนบล็อกที่สูงที่สุดของคอลัมน์ บนแผนที่จริงที่คัดลอกมาทดสอบ หาพื้นได้ 200/200 ครั้งทั้ง 10 จุดสำรวจ
- **คำสั่ง `/evergarden pets wild spawn`:** ค้นหาพื้นที่เหมาะในรัศมี 6 บล็อกรอบจุดด้านหน้า ถ้าไม่ได้จะบอกเหตุผลชัดเจน เช่น ไม่มีพื้นแข็ง ใกล้จุดเกิด หรือพื้นเป็นสิ่งก่อสร้างที่ป้องกันไว้
- **`/evergarden pets wild status`:** บอกผลการสุ่มครั้งล่าสุด และสาเหตุที่หาพื้นไม่ได้

## e2.106: เห็นได้ทั้ง Java และ Bedrock และเคลื่อนไหวเป็นธรรมชาติ

- **Bedrock:** ใช้วิธีเดียวกับบอส Sanctuary คือ ArmorStand carrier ที่ส่งให้เฉพาะผู้เล่น Bedrock แล้ว Geyser แปลงเป็น custom entity `voidscape:everpet_<ชนิด>_<วัย>` จาก pack Bedrock รุ่น **3.39.0** (36 แบบ, texture 12 ไฟล์) เซิร์ฟเวอร์ส่งท่า idle/walk/fly/sit/greet ผ่าน entity property ผู้เล่น Bedrock จึงเห็นและทำให้สัตว์เกิดได้เหมือนผู้เล่น Java ต้องใช้ Geyser ที่มี entity API (2.11 ขึ้นไป) และให้ผู้เล่นเชื่อมต่อใหม่เพื่อรับ pack
- **พฤติกรรม:** ยืนนิ่ง เดิน (ก้าวขึ้นลงได้ 1 บล็อก) หยุดพัก (ท่านั่ง 8–18 วินาที) และหันมาทักทายเมื่อผู้เล่นเข้าใกล้ 6 บล็อก หรือเมื่อคลิกขวา สัตว์ที่บินได้ (Frost Wyvern, Astral Owl, Blood Gargoyle, Abyssal Manta, Chrono Fairy และอีก 7 ชนิดใหม่ใน e2.128) จะบินขึ้น ร่อนสูงจากพื้น 2.5–4.5 บล็อก ลอยนิ่ง แล้วลงจอด และจะไม่บินออกไปเหนือ void สัตว์ที่บินไม่ได้จะไม่เล่นท่าบินเลย การหันตัวค่อยๆ เลี้ยว ไม่หักกะทันหัน
- **พื้นที่:** ขนาดพื้นที่วัดจากโมเดลจริง ร่างเด็ก 1×1 บล็อก ร่างกลางและโตเต็มวัย 3×3 บล็อก ที่ว่างเหนือหัว 2 บล็อก (เดิม 5×5 และสูง 6 บล็อก) และลองหาตำแหน่ง 24 จุดต่อการสุ่ม (`spot-attempts`) จึงเกิดบนเกาะลอยฟ้าได้บ่อยขึ้น
- **ประหยัดทรัพยากร:** สัตว์ที่ไม่มีผู้เล่นอยู่ในรัศมี 48 บล็อกจะหยุดนิ่งและไม่ส่งข้อมูลเลย ตั้งแต่ e2.107 ชิ้นส่วนโมเดลขี่ตัวรับแทนการ teleport ส่งท่าเฉพาะเมื่อเปลี่ยน และผู้เล่นแต่ละคนรับข้อมูลเฉพาะสัตว์ที่ใกล้ที่สุดไม่เกิน 6 ตัวในระยะ 56 บล็อก ดู [กันแลค](pet-companions.md#5-กันแลค-เฟส-0)

## โอกาสพบและวัย

ทุก 45 วินาที ระบบตรวจผู้เล่น Java ที่รับ resource pack แล้วใน Evergarden และสุ่มโอกาส 12% ต่อผู้เล่นหนึ่งคน ก่อนค้นหาพื้นที่ปลอดภัย ผู้ชมในโหมด Spectator ไม่กระตุ้นการเกิด การสุ่มผ่านไม่ได้รับประกันว่าจะเกิด หากพื้นที่ไม่เหมาะสมหรือสัตว์ในบริเวณนั้นครบแล้ว

เมื่อเกิดสำเร็จ โอกาสของแต่ละวัยเป็นดังนี้

| วัย | โอกาส |
| --- | ---: |
| เด็ก (`baby`) | 45% |
| กลาง (`medium`) | 38% |
| โตเต็มวัย (`adult`) | 17% |

การเกิดตามธรรมชาติเลือกตำแหน่งห่างผู้เล่น 24–48 บล็อก ต้องห่างสัตว์ป่าที่มีอยู่แล้วอย่างน้อย 48 บล็อก จำกัดทั้งโลก 16 ตัว และจำกัดบริเวณรัศมี 96 บล็อกไว้ 2 ตัว เพื่อให้พบได้ระหว่างสำรวจโดยไม่แน่นเกินไป

## พื้นที่เกิดและการดูแลจำนวน

- เกิดเฉพาะโลก Evergarden และเว้นเกาะเกิดในรัศมี 128 บล็อก
- ใช้เฉพาะ chunk ที่โหลดอยู่แล้ว ไม่เปิด chunk ใหม่เพื่อหาตำแหน่งเกิด
- ต้องมีพื้นที่ยืนปลอดภัยและที่ว่างสำหรับโมเดล ไม่เกิดในของเหลว บนพื้นอันตราย เหนือความว่าง หรือทับผู้เล่น
- เว้นพื้นที่ดันเจียน สนามบอส และโครงสร้างที่ได้รับการป้องกัน
- ตัวที่ไม่มีผู้เล่นอยู่ใกล้ภายใน 160 บล็อกจะถูกเก็บออก และแต่ละตัวอยู่ได้ 900 วินาที (15 นาที) แต่ถ้ามีผู้เล่นอยู่ใกล้ 24 บล็อกจะรอจนผู้เล่นออกห่าง (นานสุดอีก 5 นาที) แล้วจากไปพร้อมประกาย ไม่หายไปต่อหน้า
- เมื่อ chunk หรือโลกถูกถอดออก หรือปลั๊กอินปิด ระบบเก็บทั้งตัวรับและชิ้นส่วนโมเดลออก สัตว์กลุ่มนี้ไม่บันทึกค้างลงโลก

กฎกันมอนสเตอร์ของ Evergarden ยังคงทำงาน `DO_MOB_SPAWNING` ยังปิดอยู่ ระบบอนุญาตเฉพาะการเกิดแบบ `CUSTOM` ที่มีแท็ก `voidscape:wild_pet` ก่อนผ่านตัวกรอง จึงไม่เปิดให้มอนสเตอร์ธรรมดากลับมาเกิด และใส่แท็กป้องกัน LevelledMobs ตั้งแต่ก่อนเหตุการณ์เกิด

## โมเดลและ resource pack

สัตว์ป่าใช้ `NativePetRenderer` พร้อม resource pack ของตัวเองที่รวมเข้ากับ pack ของ Evergarden จึงแสดงครบ 32 ชนิด × 3 วัยได้ โดยไม่ใช้ช่องนำเข้าโมเดลของ ModelEngine ที่บอสต้องใช้ โมเดลบอสและไฟล์ต้นฉบับสัตว์เลี้ยงยังเก็บไว้ตามเดิม

ผู้เล่น Java ต้องรับ resource pack ของเซิร์ฟเวอร์ หากยังเห็น pack เก่า ใช้ `/evergarden boss pack resend` แล้วรับ pack ใหม่ ผู้เล่น Bedrock ได้โมเดลจาก pack ของ Geyser (ดูหัวข้อ e2.106 ด้านบน)

## คำสั่งสำหรับแอดมิน

ต้องเป็น OP หรือมีสิทธิ์ `evergarden.admin` / `voidscape.admin`

```text
/evergarden pets wild status
/evergarden pets wild spawn <id> <baby|medium|adult>
/evergarden pets wild clear
```

ตัวอย่าง:

```text
/evergarden pets wild spawn abyssal_manta baby
/evergarden pets wild spawn crystal_tortoise medium
/evergarden pets wild spawn frost_wyvern adult
```

คำสั่ง `spawn` ต้องใช้จากผู้เล่นใน Evergarden ระบบหาพื้นปลอดภัยประมาณ 6 บล็อกด้านหน้าผู้เรียก เหมาะสำหรับตรวจโมเดลและเปรียบเทียบวัย ใช้ `status` ตรวจสถานะระบบและจำนวนที่มีอยู่ และใช้ `clear` เก็บสัตว์ป่าที่ระบบนี้สร้างออก คำสั่งดูโมเดลแอดมินเดิม `/evergarden pets spawn ...` ยังแยกใช้งานได้ตามเดิม

หลังปรับค่าการเกิดใน `config.yml` ใช้ `/evergarden reload` เพื่ออ่านค่าของสัตว์ป่าใหม่ การโหลด ModelEngine ใหม่ไม่กระทบระบบวาดสัตว์ป่าซึ่งทำงานแยกกัน

ค่าที่ปรับได้อยู่ใต้ `pets.wild-spawns` โดยไม่ต้องเพิ่ม `model-preview.install-species` สำหรับสัตว์ป่า:

```yaml
pets:
  wild-spawns:
    enabled: true
    attempt-interval-seconds: 45
    chance-per-player: 0.12
    stage-weights:
      baby: 85
      medium: 13
      adult: 2
    max-active-world: 16
    max-nearby-player: 2
```
