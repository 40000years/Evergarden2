# เฟส 3 ของบอส: ปรับตัวแบบ Phlegethon และดาเมจ ×2 (e2.196)

ตั้งแต่ e2.196 บอสทุกตัวที่มีเฟส 3 ได้กลไก **ปรับตัวต้านอาวุธ (adaptation)** ของ Phlegethon และตีแรงขึ้น **×2** เฉพาะในเฟส 3

| บอส | เฟส 3 เริ่มที่ |
|---|---|
| Arkhaia | 35% (หลังพิธีแม่น้ำรอบสอง) |
| Seraphon | 30% |
| ผู้พิพากษาไร้ร่าง (Ancient Judge) | แกนเหลือ 35% — เฟสหัวใจเปิดตลอด |
| มังกร Dragon Nest ทั้ง 3 ตัว (Vharok, Vaelthyr, Glaceryn) | 25% (คลั่ง) |
| บอสมิติ 4 ตัว: Cinder Colossus, Soul-Eater Hound, Crystal Moth Queen, Unlit Sun | 30% |

บอสที่ไม่มีเฟส 3 (วิญญาณแม่น้ำ, บอสวิหาร Sanctum, บอส Sanctuary ในโลกปกติ) ไม่เปลี่ยน Phlegethon ยังใช้กลไกเดิมของตัวเองทุกเฟส

## ปรับตัวต้านอาวุธ

กฎเดียวกับ Phlegethon (ผู้พิพากษาใช้แบบลดได้แค่ครึ่งเดียว ดูด้านล่าง):

- ตีซ้ำด้วยอาวุธตระกูลเดิม ดาเมจลดครึ่งจากครั้งก่อน: 100% → 50% → 25% → 12.5% …
- เปลี่ยนตระกูลอาวุธ ดาเมจกลับมาเต็มทันที และกลับไปใช้ตระกูลเดิมก็เริ่มเต็มใหม่ (สลับดาบ ↔ ขวานทุกครั้งที่ตี = เต็มแรงตลอด)
- ตระกูลอาวุธ: ดาบ ขวาน อีเตอร์ พลั่ว จอบ นับเป็นตระกูลเดียวกันไม่ว่าวัสดุอะไร · ธนู หน้าไม้ ตรีศูล มือเปล่า แยกกัน · ลูกธนูนับตามอาวุธที่ยิงออกไป (สลับของในมือก่อนลูกถึงไม่ได้ผล) · ไอเท็มอื่นและกระสุนชนิดอื่นแยกตามชนิด
- **หนึ่งบอสหนึ่งสาย ใช้ร่วมกันทั้งปาร์ตี้** ถ้าเพื่อนตีด้วยอาวุธคนละตระกูลสลับกัน ทุกคนตีเต็มแรง
- ตีพลาด ตีถี่เกินจนถูกปัด ตีจากนอกวง หรือตีตอนบอสมีเกราะเฟส/ช่วงเปลี่ยนเฟส ไม่นับเข้าสาย
- action bar บอกตระกูลที่บอสปรับตัวและดาเมจที่เหลือ เช่น `⚔ Seraphon ปรับตัวต้านดาบ ×0.25 — สลับอาวุธเพื่อตีเต็มแรง` และมีประกายมนต์ (ENCHANT) ที่ตัวบอส
- เริ่มเฟส 3 ทุกครั้งสายจะว่าง การต่อสู้ใหม่ ปาร์ตี้ตายหมดแล้ว Arkhaia เริ่มเฟสใหม่ หรือมังกรตื่นใหม่ จะล้างสาย

ข้อควรรู้รายบอส:

- **ผู้พิพากษา** ใช้แบบ **ลดได้แค่ครึ่งเดียว** (`half` — กฎเดียวกับ Phlegethon ตอนอยู่ในพิธี): ตีซ้ำตระกูลเดิมได้ 100% → 50% → 50% … ไม่ต่ำกว่านี้ เพราะเฟส 3 รับเฉพาะอาวุธประชิดอยู่แล้ว (ดาบ ขวาน ค้อน Mace ตรีศูลแบบถือตี มือเปล่า) และการสลับของในมือรีเซ็ตคูลดาวน์การตี สลับอาวุธยังได้ 100% เหมือนเดิม ปรับตัวเฉพาะการตีหัวใจ (ส่วนเดียวที่รับดาเมจในเฟส 3)
- **Cinder Colossus** การตีแกนหลังยังนับเกจขัดจังหวะ "เตาหลอมปะทุ" เต็มค่าก่อนปรับตัว ไม่ทำให้สตันยากขึ้น
- **มังกร** ลูกธนูและเวทที่โดนกล่องฮิตก็ปรับตัวเหมือนกัน (เวทนับตามของที่ถือ)

## ดาเมจ ×2

การโจมตีของบอสเองในเฟส 3 แรงเป็น 2 เท่าของค่าปัจจุบัน (รวมตัวคูณเดิมทั้งหมด เช่น Realm Brand, rend ทะลุ Protection, มังกรคลั่ง ×1.15 อยู่แล้วจึงเป็น ×2.3 จากเฟส 1) มินเนียน วิญญาณแม่น้ำ และบอสวิหารที่ผู้พิพากษาเรียกออกมาไม่เปลี่ยน

**ท่าที่คิดดาเมจเป็น % ของเลือดสูงสุด** ได้ ×2 เหมือนกัน แต่หยุดที่ **95% ของเลือดสูงสุด** (`percent-blow-cap`) และไม่มีทางเบากว่านอกเฟส 3 ถ้า ×2 แบบตรง ๆ ท่าพวกนี้จะฆ่าจากเลือดเต็มทันทีไม่ว่าใส่ชุดอะไร:

| ท่า | นอกเฟส 3 | เฟส 3 (×2, เพดาน 95%) |
|---|---|---|
| Arkhaia กวาดดาบ (Sweep) | 55% | 95% |
| Arkhaia Execute | 60% | 95% |
| Seraphon ลำแสงสุริยะ (Solar) | 60% | 95% |
| Seraphon แสงระเบิด (Radiant burst) | 40% | 80% |
| ผู้พิพากษา เวทสีแดง | ประมาณ 72–104% (แรงอยู่แล้ว) | 95% ถ้าเดิมต่ำกว่า · เท่าเดิมถ้าเดิมเกิน 95% |

เลือดเต็มรอดได้หนึ่งครั้งแบบเฉียดตาย (ต้องฮีลทันที) Protection, Resistance, absorption และ Totem ยังลดหรือกันได้ตามปกติสำหรับท่าที่ไม่ทะลุเกราะ ผู้พิพากษาเวทแดงแรงเกือบเต็มหลอดอยู่แล้ว เฟส 3 จึงแรงขึ้นไม่มาก เพิ่มความยากจากการปรับตัวต้านอาวุธแทน

ถ้าอยากให้ ×2 ตรง ๆ (ท่าเหล่านี้ตายทันที) ตั้ง `boss-phase-three.percent-blow-cap: 0`

## ตั้งค่า (`config.yml`)

```yaml
boss-phase-three:
  adaptation:               # full = ลดครึ่งทุกครั้งไม่มีพื้น (Phlegethon) · half = ลดถึง 50% แล้วหยุด · off = ปิด
    arkhaia: full
    seraphon: full
    judge: half
    dragons: full
    realm: full             # บอสมิติทั้ง 4 ตัว
  damage-multiplier:        # 1.0 = เท่าเดิม
    arkhaia: 2.0
    seraphon: 2.0
    judge: 2.0
    dragons: 2.0
    realm: 2.0              # บอสมิติทั้ง 4 ตัว
  percent-blow-cap: 0.95    # ท่า % เลือดสูงสุด ×2 ได้ไม่เกินเท่านี้ของเลือดสูงสุด · 0 = ×2 ตรง ๆ
```

ค่าถูกอ่านทุกครั้งที่ตี/โดนตี แก้แล้ว `/evergarden reload` (หรือรีสตาร์ท) ได้เลย config เก่าที่ไม่มีหัวข้อนี้ใช้ค่าข้างบนเป็นค่าเริ่มต้น
