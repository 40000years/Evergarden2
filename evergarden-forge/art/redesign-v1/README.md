# Forge gem art refinement preview

Generated with the built-in imagegen tool on 2026-11-01 in response to feedback about the procedural 0.5.0 icons.

- `gem-fire-concept.png`: initial generated fire crystal concept.
- `gem-fire-pixel.png`: selected refinement with stronger pixel clusters and facet separation.
- `gem-fire-pixel-16.png`, `gem-fire-pixel-32.png`, `gem-fire-pixel-64.png`: nearest-neighbor size checks; `-zoom` files enlarge those checks for inspection.
- `fire-gem-prompt.txt` and `fire-gem-pixel-refinement-prompt.txt`: complete generation and refinement prompts.

This is a style preview. The delivered 0.5.0 resource packs and JAR have not been rebuilt from it. Review the small inventory previews when selecting the eventual production artwork; the enlarged source alone does not establish small-size quality.
