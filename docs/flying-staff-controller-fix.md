# คทาบินสำหรับจอย Bedrock — Advance Magic 1.20.1

รุ่น `1.20.1-controller-flight` แก้ปัญหาที่ตรวจพบใน
[รายงานเดิม](flying-staff-controller-audit.md) และเพิ่มการรับน้ำหนักจอยก่อน
Geyser แปลงอินพุตเป็นปุ่มเดินของ Java

## พฤติกรรมหลังแก้

- ซ้าย/ขวาตรงกับทิศของผู้ขี่ทั้ง Java และ Bedrock
- จอย Bedrock บน Geyser ที่อยู่เครื่องเดียวกับปลั๊กอินควบคุมความเร็วตามน้ำหนักโยกได้
  มี radial deadzone 0.15 ป้องกันสัญญาณใกล้จุดกึ่งกลาง สัดส่วนแกนทแยงยังคงอยู่
- ขณะเดินหน้าบน Bedrock เงย/ก้มกล้องเพื่อไต่ขึ้น/ลงอย่างต่อเนื่อง
  ในช่วง +/-12° จะรักษาระดับ และเพิ่มความเร็วแนวดิ่งจนเต็มที่ที่ 60°
  น้ำหนักเดินหน้ายังมีผลกับความเร็วขึ้นลง กระโดดขึ้นตรง ๆ ได้เหมือนเดิม
  ปล่อยปุ่มเดินและปุ่มกระโดดแล้วลอยค้าง Java ยังคงใช้กระโดดและก้มเกิน 35° ตามเดิม
- เรียกคทาแล้วรอแอนิเมชัน 12 ticks หรือประมาณ 0.6 วินาที จากนั้นกดใช้ไอเทมอีกครั้ง
  เมื่อคทาอยู่ในระยะ 3 บล็อกเพื่อขึ้นขี่ได้ ไม่ต้องเล็งโมเดลให้ตรง
  ต้องไม่มีสิ่งกีดขวางระหว่างผู้เล่นกับคทา
- กดใช้ติดกันภายใน 8 ticks นับเป็นชุดเดียว ไม่หักความทนทานเพิ่มหรือเริ่มแอนิเมชันใหม่
  หลังขึ้นขี่ก็ตัดการใช้ซ้ำลักษณะนี้เพื่อไม่ให้ Turbo สลับไปมา
  เว้นจาก use event ล่าสุดอย่างน้อย 8 ticks จึงจะสลับ Turbo ครั้งถัดไปได้
- คลิกคทาที่เรียกไว้ขณะถือคทาธาตุหรือคทาซ่อมขึ้นขี่ได้ และไม่ใช้เวท/ค่าซ่อม
  การยกเลิก event จากระบบป้องกันพื้นที่ยังมีผลตามเดิม
- ระยะตรวจพื้นที่ว่างสูงถึง 3.3 บล็อกเหนือจุดอ้างอิงยาน ครอบคลุมหัวของผู้ขี่
  ทั้งตอนเรียก ขึ้นขี่ และเคลื่อนที่ ป้องกันยานพาหัวเข้าไปในเพดานต่ำ
- ปิดระบบหรือถอนสิทธิ์แล้วจะยุติการขี่ด้วย เสียคทาระหว่างขี่เหนือ void
  หรือปิดระบบเหนือ void จะส่งกลับจุดเรียกแทนปล่อยให้ตกลงไป
  การถอดยานฉุกเฉินให้ Slow Falling ระยะยาวเท่าการลงของ Bedrock

การออกจากยานยังใช้ปุ่มย่อง/ลงพาหนะ จึงไม่ต้องยกเลิกการลงจากรถของ Bedrock
ที่เคยทำให้กล้องกระตุก ไม่มีการเพิ่มสิทธิ์บินแบบ creative

## การรับอนาล็อกและ fallback

ตัวรับอินพุตติดเฉพาะระหว่างขี่และถอดเมื่อเลิกขี่ รวมถึงกรณีไม่มี Bukkit player
เหลือใน registry แล้ว ทำงานบน event loop ของ upstream Bedrock session
อ่าน packet โดยไม่ยกเลิก เปลี่ยน หรือส่งซ้ำ และส่งต่อให้ handler เดิมเพียงครั้งเดียว
การถอดจะคืน handler เดิมเฉพาะเมื่อตัวยังเป็น wrapper ของปลั๊กอินนี้

Snapshot เป็น immutable ข้าม thread; หาก packet จอยเก่ากว่า 500 ms จะใช้ทิศทาง
Jump และ Sprint ที่เป็นกลาง จึงไม่กลับไปใช้ boolean ค้างแทนอนาล็อกเก่า
Sprint รองรับทั้งปุ่มค้าง สถานะกำลังวิ่ง และการเริ่มวิ่ง ส่วน Stop Sprint
ยกเลิกสถานะ/การเริ่ม แต่ปุ่ม Sprint ที่ยังถืออยู่เป็นคำสั่งแยกที่ยังทำงานได้

ทดสอบกับ Geyser `2.12.0-SNAPSHOT` commit `bc81f9e`. หากใช้ Geyser แยกเครื่อง
หรือเวอร์ชันที่ไม่มี API ภายในที่จำเป็น ตัวรับอนาล็อกจะใช้ไม่ได้และแจ้งเตือนหนึ่งครั้ง
การเดินจะใช้ปุ่มแบบเดิม ส่วนทิศซ้ายขวา ระดับบิน การขึ้นขี่ และการตรวจชนยังได้รับการแก้
ไม่ต้องติดตั้งหรือแก้ JAR ของ Geyser

ตั้งค่าต่อไปนี้ใน config ของ Advance Magic ได้ โดย config เก่าจะได้รับค่าเริ่มต้น
ผ่านระบบ defaults เดิมของปลั๊กอิน:

```yaml
flying-staff:
  bedrock-controls:
    analog-deadzone: 0.15
    pitch-deadzone: 12.0
    pitch-full-speed: 60.0
```

ไม่มีการอัปเดตเซิร์ฟเวอร์จริงจาก workspace ในงานนี้
