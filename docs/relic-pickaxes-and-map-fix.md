# อีเต้อ 3D และแก้ร้านแผนที่ Seraph (e2.139 → e2.140)

Release `3.0.0-e2.140-pickaxe-bedrock-fix` · แพ็ก Bedrock **3.59.0** · ต่อจาก e2.138-ancient-balance

**e2.140:** ใน e2.139 กระดูกหลักของโมเดลอีเต้อฝั่ง Bedrock ชื่อ `body` ซึ่งซ้ำกับกระดูกลำตัวผู้เล่น Bedrock จึงเอาโมเดลไปติดกับลำตัวแทนมือ (เห็นเป็นกล่องสีม่วงใหญ่เต็มจอ) แก้เป็น `tool` และเพิ่มการตรวจชื่อกระดูกไว้ใน `check_relic_pickaxes.py` แล้ว ฝั่ง Java ไม่เปลี่ยน

## อีเต้อ 3D

ภาพ: [previews/relic-pickaxes/pickaxes.png](../previews/relic-pickaxes/pickaxes.png) (เรนเดอร์จากไฟล์จริง ไม่ใช่ภาพในเกม)

| ไอเทม | ดีไซน์ |
|---|---|
| **Rift Excavator** · อีเต้อแยกพิภพ | หัวอีเต้อคู่สีม่วงมิติ รอยแยกเรืองแสงวิ่งตามแนวคมทั้งสองด้าน ปลายแหลมเรืองแสง ผลึกรอยแยกงอกขึ้นจากหัว 3 แท่ง คริสตัลมิติลอยกลางเบ้า ด้ามออบซิเดียนพันหนัง รอยเรืองแสงไหลลงตามด้าม ปุ่มท้ายเป็นอัญมณีมิติ |
| **Smelter's Pickaxe** · อีเต้อหลอมเพลิงมิติ | กลางหัวเป็นเตาหลอมทองเหลือง มีตะแกรงเหล็กเห็นไฟลุกด้านใน หมุดทอง และปล่องควันมีเปลวไฟ คมเหล็กร้อนแดงขึ้นจนปลายหลอมละลาย ด้ามไม้ไหม้พันหนังกับทองเหลือง ปุ่มท้ายเป็นอัญมณีถ่านเพลิง |

- **Java:** โมเดล 3D ในมือ บนพื้น และในกรอบ ส่วนช่องเก็บของแสดงไอคอนที่เรนเดอร์จากโมเดล 3D
- **Bedrock:** attachable 3D ใช้ระบบถือแบบเดียวกับอาวุธนักผจญภัยประชิด (ตรวจแล้วว่ามุมสามตรงกับ Java ทุกมุมของทุกกล่อง) ฮอตบาร์ใช้ไอคอน 3D ภาพเดียวกัน
- ความสามารถ (ขุด 3×3, หลอมอัตโนมัติ) และ mapping ของ Geyser เหมือนเดิม อีเต้อเดิมในเกมเปลี่ยนเป็นโมเดลใหม่เองหลังผู้เล่นรับแพ็กใหม่

โค้ด: `evergarden/tools/relic_pickaxe_assets.py` (`build_packs.py` เรียกต่อจากอาวุธนักผจญภัย) · ภาพ: `python evergarden/tools/relic_pickaxe_assets.py`

## ร้านแผนที่ Seraph

- แผนที่ที่แลกไม่ได้บอกเหตุผลจริง เช่น "ไม่มีวิหาร Seraphon แบบใหม่ในระยะ 12,000 บล็อก", "อยู่นอกขอบโลก", "ปิดใช้งานอยู่" และบอกด้วยถ้านับระยะจากจุดเกิดของโลก Evergarden เพราะผู้เล่นไม่ได้อยู่ในโลกนั้น
- บอส Evergarden (Judge, Arkhaia, Seraphon): ถ้าในระยะไม่มีวิหารใหม่ที่ยังไม่เคยไป จะขายแผนที่ไปวิหารใกล้สุดที่เคยไปถึงแล้วแทน (บอสเกิดใหม่ได้) และบอกไว้บนแผนที่ว่า "คุณเคยไปถึงที่นี่แล้ว" · ถ้ามีวิหารใหม่ ยังเลือกวิหารใหม่ก่อนเหมือนเดิม
- Sanctuary โลกปกติยังข้ามที่เคยไปแล้วเหมือนเดิม
