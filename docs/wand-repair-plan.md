# แผนระบบซ่อมคทา Advance Magic

> อัปเดต: ลงโค้ดระบบแล้ว รายละเอียดการใช้งาน ค่าที่นำมาใช้ ภาพแท่น และขอบเขตการตรวจอยู่ใน [wand-repair-implementation.md](wand-repair-implementation.md) เนื้อหาด้านล่างเก็บข้อเสนอเดิมไว้เป็นที่มา

สถานะ: ข้อเสนอสำหรับอัปเดตถัดไป ยังไม่ใช่รายการที่ลงโค้ดแล้ว ตัวเลขในหัวข้อ “ค่าทดลอง” ปรับหลังลองเล่นได้

## เป้าหมายและกติกาที่ตกลงกัน

- ผู้เล่นซ่อมคทาที่ใช้หมดได้โดยไม่ต้องพึ่ง Core เพิ่มเพดานความทนทานที่หายาก
- มีสองทางซ่อม: ใช้ Core กับแท่นใน structure หรือใช้คทาซ่อมระยะไกล
- Core of Restoration เป็นไอเท็มใช้ซ่อม ไม่ใช้คราฟต์คทา
- ใช้ Core เวทของคทาชนิดใดก็ได้ที่ **ยังไม่ได้คราฟต์** แทน Core of Restoration ที่แท่นได้
- คทาซ่อมระยะไกลซ่อมคทาอื่นได้รวม 5 ครั้ง ตัวคทาซ่อมเองเติมจำนวนครั้งไม่ได้
- Whale, Hanging Garden และ Observatory ต้องน่าออกตามหาและมีโอกาสพบแห่งที่ไม่มีแท่น

## วิธีเล่นที่ผู้เล่นเห็น

**ที่แท่น:** พบแท่น → ใส่ Core of Restoration หรือ Core เวทที่ยังไม่ได้ใช้ → โยนคทาที่เสียหายเข้าใจกลางแท่น → พิธี 10 วินาที → ได้คทากลับมาที่จำนวนครั้งเต็มตามเพดานเดิม Core ถูกใช้ 1 อันต่อการซ่อม 1 ครั้ง แท่นที่เคยพบกลับมาใช้ซ้ำได้

**คทาซ่อมระยะไกล:** ถือคทาซ่อมแล้วคลิกขวาผู้เล่นในระยะที่กำหนด ผู้รับต้องถือคทา Advance Magic ที่เสียหายอยู่ คทาของผู้รับกลับมาเต็มทันที และคทาซ่อมลดจาก 5 เป็น 4 ครั้ง ทำได้จนเหลือ 0/5; คทาซ่อมชิ้นนั้นชาร์จกลับไม่ได้

การซ่อมทั้งสองแบบเติมเฉพาะจำนวนครั้งที่เหลือ ไม่เพิ่มเพดานความทนทาน ไม่เปลี่ยนระดับดาเมจ คูลดาวน์ หรือ Mastery และไม่รับคทาที่เต็มอยู่แล้ว

## แยกของเดิมกับของใหม่

| ไอเท็ม | บทบาท | คราฟต์คทาได้ | ใช้บูชาที่แท่น |
| --- | --- | --- | --- |
| Wand Repair Core เดิม | เพิ่มเพดานคทา +5 และเติม +5 ตามระบบเดิม | ไม่ได้ | เสนอว่าไม่ได้ เพื่อรักษาหน้าที่เดิม |
| Core of Restoration ใหม่ | ซ่อมคทา 1 ครั้ง | ไม่ได้ | ได้ |
| Core of Lightning/Frost ฯลฯ ที่ยังไม่ได้ใช้ | คราฟต์คทาเวท | ได้ ตามชนิด | ได้ 1 ครั้ง |
| คทาซ่อมระยะไกล | ซ่อมคทาอื่นได้ 5 ครั้งตลอดอายุ | ไม่ใช่ Core | ใช้ซ่อมตัวเองไม่ได้ |

ห้ามนำคทาที่คราฟต์แล้วไปแยกเอา Core กลับมาใช้ซ้ำ Core ใหม่ต้องมีข้อมูลประจำไอเท็มคนละชนิดกับ Core เวทและ Wand Repair Core เดิม การตรวจต้องดูข้อมูลนี้ ไม่ดูแค่ชื่อหรือวัสดุที่ผู้เล่นปลอมได้

## แท่นและการสำรวจ

- ทั้งสาม structure ใช้ระบบแท่นเดียวกัน แต่มีห้องพิธีและเอฟเฟกต์เฉพาะ: หัวใจวาฬ, บ่อน้ำรากไม้, เลนส์รวมแสงดาว
- สุ่มว่ามีแท่นหรือไม่จาก seed และตำแหน่ง structure แล้วบันทึกผลถาวร เพื่อไม่ให้การรีสตาร์ตสุ่มใหม่
- แห่งที่ไม่มีแท่นยังมีกล่อง Core และร่องรอยนำทางไปยัง structure ที่มีแท่น ผู้เล่นจึงไม่เดินทางเสียเที่ยว
- แท่นใช้ซ้ำได้; เหตุผลให้ออกหา structure ใหม่คือ Core เพิ่มเติมและโอกาสพบคทาซ่อม ไม่ใช่การบังคับทิ้งแท่นเดิม
- ให้เอฟเฟกต์พิธีเด่นตอนใช้งาน แต่โครงสร้างแท่นใช้บล็อกถาวรเพื่อให้เห็นได้ทั้ง Java และ Bedrock

## ค่าทดลองสำหรับการบาลานซ์

| ค่า | จุดเริ่มทดลอง | เหตุผล |
| --- | --- | --- |
| โอกาสมีแท่นใน structure | 60% | มีความลุ้น แต่ส่วนใหญ่ที่พบช่วยซ่อมได้ |
| Core of Restoration เพิ่มในกล่อง | 1 ชิ้นต่อ structure; ใส่กล่องหลัก | เพิ่มแหล่งซ่อมที่คาดการณ์ได้ โดยยังต้องสำรวจ |
| โอกาสพบคทาซ่อมระยะไกล | 10% ต่อ structure ในกล่องหลัก | ของพิเศษที่ซ่อมได้รวม 5 ครั้ง จึงไม่ควรดรอปบ่อย |
| ระยะคทาซ่อม | 8 บล็อกและต้องมองเห็นเป้าหมาย | ใช้ช่วยเพื่อนระหว่างเดินทางโดยไม่ครอบคลุมพื้นที่กว้าง |
| เวลาแท่นทำพิธี | 10 วินาที | มีจังหวะให้เห็นพิธีและยกเลิกได้ |
| อัตราพบ structure ในพื้นที่ใหม่ | เริ่มวัดที่ 3% ต่อชนิดต่อช่องสุ่ม จากปัจจุบัน 1% | ลดระยะค้นหาโดยยังคงเป็นจุดหมายในการสำรวจ |

การเพิ่มอัตราพบ structure ต้องเปลี่ยนค่าที่บันทึกใน `plugins/Evergarden/world-layout.yml` สำหรับ **พื้นที่ที่ยังไม่สำรวจ** ด้วย การแก้ `config.yml` อย่างเดียวไม่เปลี่ยนโลกเดิม และห้ามย้าย structure ที่เกิดแล้ว ตรวจจำนวนและระยะจริงด้วย seed หลายแบบก่อนตัดสินค่า 3%

## ข้อกำหนดการทำงานที่ต้องกันพลาด

1. คทาซ่อมระยะไกลเป็นไอเท็มคนละชนิดกับคทาเวทปกติ มีจำนวนครั้ง 5/5 ของตัวเอง ระบบ Wand Repair Core, แท่น, ทั่ง, Mending และคำสั่งซ่อมปกติห้ามเพิ่มจำนวนครั้งให้มัน
2. ระยะไกลรับเฉพาะคทา Advance Magic ที่ผู้รับถืออยู่ ตรวจเป้าหมาย ระยะ สายตา และจำนวนครั้งอีกครั้งตอนทำสำเร็จ ป้องกันกดซ้ำหรือสลับไอเท็มระหว่างทาง
3. แท่นตรวจชนิด Core และคทาก่อนรับของ หัก Core กับเติมคทาในขั้นตอนเดียว เกิดการหลุด/ปิดเซิร์ฟเวอร์กลางพิธีแล้วคืนของครบหรือทำรายการสำเร็จเพียงครั้งเดียว
4. หลีกเลี่ยงการโยนไอเท็มจริงค้างบนพื้น: ถ้าภาพพิธีต้องให้คทาลอย ให้ใช้ entity แสดงผล ส่วนไอเท็มจริงเก็บในสถานะธุรกรรม ป้องกัน ClearDropsPlus เก็บทิ้ง
5. กล่องเก่าที่เปิดหรือถูกทุบไปแล้วต้องไม่เติมของย้อนหลัง กล่องใหม่ใช้ marker รุ่นใหม่เพื่อกันของเกิดซ้ำเมื่อโหลด chunk
6. คทาเก่าและ Core อัปเกรดเดิมใช้ได้เหมือนเดิม คทาที่เหลือ 0 ครั้งสามารถนำไปซ่อมที่แท่นหรือให้ผู้ถือคทาซ่อมช่วยได้

## งานที่จะลงมือเมื่อเริ่มพัฒนา

1. เพิ่มตัวตนของ Core of Restoration และคทาซ่อมใน `advance-magic` พร้อมวิธีตรวจจาก persistent data และข้อความอธิบายจำนวนครั้ง
2. กำหนดวิธีที่ Evergarden เรียกตรวจและเติมคทาผ่าน Advance Magic โดยตรง พร้อมระบุลำดับโหลดปลั๊กอินให้แน่นอน เพื่อไม่ให้สองปลั๊กอินตีความข้อมูลคทาคนละแบบ
3. เพิ่มการซ่อมสองทาง พร้อมการตัด Core, การคืนไอเท็ม และการกันซ่อมคทาซ่อม
4. เพิ่มแท่น 3 รูปแบบใน blueprint ของ Whale/Garden/Observatory และจุดโต้ตอบที่ตรงกับภาพ
5. เพิ่ม Core ใหม่และโอกาสคทาซ่อมในกล่องด้วย seed ที่คงที่ และย้าย marker โดยไม่เติมของให้กล่องที่เคยเปิด
6. ปรับความถี่ structure สำหรับพื้นที่ใหม่ผ่านข้อมูลโลกที่บันทึกไว้ แล้ววัดความหนาแน่นจริง
7. ตรวจบน Paper จริง: คทาเก่า, Core เวททุกชนิด, Core ปลอม, พิธีถูกยกเลิก, เซิร์ฟเวอร์รีสตาร์ต, กล่องที่เปิดแล้ว, Java และ Bedrock

## จุดตัดสินใจก่อนกำหนดค่าถาวร

- Core of Restoration ดรอปแน่นอนทุก structure หรือมีโอกาสดรอปบางแห่ง? แผนนี้เริ่มด้วยแบบแน่นอนเพื่อแก้ฟีดแบคว่าของซ่อมหายาก
- คทาซ่อมระยะไกลควรดรอปจากกล่อง structure ตามค่าทดลอง 10% หรือเป็นรางวัลกิจกรรมเฉพาะ? ทั้งสองแบบยังคงเงื่อนไข 5 ครั้งและซ่อมตัวเองไม่ได้
- โอกาสมีแท่นและความถี่ structure ต้องปรับจากเวลาที่ผู้เล่นจริงใช้เดินหา ไม่ควรล็อกตัวเลขจากความรู้สึกอย่างเดียว
