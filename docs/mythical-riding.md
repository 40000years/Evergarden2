# พาหนะสัตว์ตำนาน

Evergarden `3.0.0-e2.179-mount-refinement` · Bedrock pack **3.68.0**

สัตว์ตำนานโตเต็มวัยทั้งห้าชนิดขึ้นขี่ได้โดยไม่ใช้มานา Fenrir เป็นพาหนะภาคพื้นดิน อีกสี่ชนิดบินได้ ขึ้นขี่ด้วย `/pet ride` ปุ่มอานม้าใน `/pet` หรือคลิกขวาด้วยมือเปล่า ลงด้วยปุ่มย่องหรือ `/pet dismount`

| พาหนะ | การเคลื่อนที่ | ความสามารถระหว่างขี่ |
|---|---|---|
| Fenrir | วิ่ง 14 บล็อก/วินาที, Sprint 21 บล็อก/วินาที, กระโดดราว 6–7 บล็อก | มีแรงโน้มถ่วง กระโดดซ้ำกลางอากาศไม่ได้ บินไม่ได้ |
| Aetherius | บิน 9.72 บล็อก/วินาที, Sprint ×1.5 | Night Vision I, Regeneration I, Strength I, Absorption I, Speed I |
| Ignis Draconis, Zephyros, Solaris | บิน 9.72 บล็อก/วินาที, Sprint ×1.5 | สกิลตัวติดตามเดิม |

Aetherius ให้บัฟเฉพาะผู้ขี่ ล้างเฉพาะบัฟที่พาหนะให้เมื่อลง วาร์ป ตาย ออกจากเกม และปิดปลั๊กอิน รักษาบัฟจากยาและแหล่งอื่นที่มีอยู่แล้ว Absorption I ให้โล่สองหัวใจ เริ่มได้ครั้งละ 120 วินาที ไม่เติมโล่ที่ถูกตีหายขณะขี่ และขึ้นลงซ้ำไม่รีเซ็ตคูลดาวน์ เอฟเฟกต์มีอายุจำกัดและต่ออายุระหว่างขี่เพื่อไม่ตกค้างถาวรหากเซิร์ฟเวอร์หยุดผิดปกติ

| การควบคุม | Java | Bedrock |
|---|---|---|
| วิ่ง/บินแนวนอน | ปุ่มเดินตามทิศกล้อง | ปุ่มเดิน/จอยตามทิศกล้อง |
| กระโดด Fenrir | กระโดดขณะอยู่บนพื้น | กระโดดขณะอยู่บนพื้น |
| บินขึ้น (อีกสี่ชนิด) | กระโดด | กระโดด หรือเดินหน้าพร้อมเงยกล้อง |
| บินลง (อีกสี่ชนิด) | เดินหน้าพร้อมก้มกล้องเกิน 35° | เดินหน้าพร้อมก้มกล้อง |
| เร่ง | Sprint | Sprint |
| ลงจากสัตว์ | ย่อง หรือ `/pet dismount` | ย่อง หรือ `/pet dismount` |

Fenrir ใช้ท่าวิ่งที่ขยับขา ข้อเท้า ลำตัว หัวและหาง ความเร็วแอนิเมชันเปลี่ยนตามความเร็วจริง และกลับ idle เมื่อหยุด Ignis ยกหางและเปิดส่วนปลายที่ม้วนอยู่ พร้อมคลื่นสะบัดจากโคนถึงเปลวไฟ ขา ลำตัวและหัวขยับตามจังหวะปีก Aetherius ขยับขาและหางในท่าบิน ทั้ง Java และ Bedrock ใช้คีย์เฟรมเดียวกัน

ก่อนขึ้นขี่ต้องเห็นตัวสัตว์ อยู่ใกล้กัน มีพื้นที่เหนือหัว และไม่มีข้อห้ามสัตว์ติดตาม เช่น พักฟื้น อยู่ในรังผสมพันธุ์ หรืออยู่ใกล้บอส การเคลื่อนที่ตรวจระยะสั้น ป้องกันทะลุกำแพง เพดาน ขอบโลก และ chunk ที่ยังไม่โหลด Fenrir ก้าวขึ้นสิ่งกีดขวางสูงหนึ่งบล็อกได้ การเดินตามและช่วยสู้กลับมาทำงานหลังลงจากสัตว์

ลงกลางอากาศเหนือพื้นจะได้ Slow Falling หากด้านล่างเป็น Void จะส่งกลับจุดขึ้นขี่ที่ปลอดภัย การวาร์ปจริงไปตามปลายทางตามปกติและล้างพาหนะเก่า การเปลี่ยนตัวติดตาม เก็บเข้าคอก เปลี่ยนโหมด ตาย ออกจากเกม และปิดปลั๊กอินล้างที่นั่งกับสิทธิ์ anticheat ชั่วคราว ไม่ให้ creative flight แก่ผู้เล่นและไม่เปลี่ยนค่ามานาของไม้เท้า

```yaml
pets:
  riding:
    enabled: true
    adult-only: true
    horizontal-speed: 0.486
    vertical-speed: 0.288
    sprint-multiplier: 1.5
    fenrir:
      horizontal-speed: 0.7
      jump-velocity: 1.0
    aetherius:
      absorption-cooldown-seconds: 120
```

ติดตั้งด้วย `dist/evergarden.jar` แล้วรีสตาร์ตเซิร์ฟเวอร์พร้อม Geyser ให้ Bedrock รับแพ็ก 3.68.0 ค่าที่เพิ่มถูกเติมใน config เดิม ไม่ต้องลบข้อมูลสัตว์หรือโลก ภาพ texture และแพ็ก Java คงเดิมทุกไบต์ เปลี่ยนเฉพาะแอนิเมชันที่เซิร์ฟเวอร์ใช้และแอนิเมชันในแพ็ก Bedrock ลิงก์และ SHA ของแพ็ก Java เดิมบน GitHub คงเดิม ไม่มีแพ็ก Java ใหม่ต้องเผยแพร่

ผ่านชุดทดสอบบน Paper **1,032 ข้อ** รวมระบบสัตว์และไข่เดิม พาหนะทั้งห้าชนิด มานาศูนย์ การกระโดดและลงพื้นของ Fenrir กระโดดซ้ำกลางอากาศไม่ได้ วิ่งชนกำแพง ก้าวข้ามหนึ่งบล็อก การควบคุม Bedrock บัฟ Aetherius ครบห้าอย่าง การไม่เติมโล่ซ้ำ คูลดาวน์ขึ้นลง และการรักษาบัฟจากภายนอก โมเดลผ่าน 377,130 ข้อ และ native export ผ่าน 664,708 ข้อ

การตรวจใช้ผู้เล่นจำลองบน Paper และภาพพรีวิวจากโครงโมเดลจริง รายงานอยู่ใน `output/mythical-mount-refinement/pet-result.txt` และ `motion-contact-sheet.png` ยังไม่ได้ตรวจภาพกับไคลเอนต์ Java/Bedrock ที่เชื่อมต่อจริง
